# AI prompts

Task templates, overridable file-by-file in `~/.config/omacell/ai/prompts/`.

- `card.md` — system text that fences a workbook card as data (WP-22).
- `plan.md`, `formula.md`, `complete.md`, `import.md`, `audit.md`, `describe.md`, `agent.md`, `cell.md` and task-specific cell templates (WP-23).
