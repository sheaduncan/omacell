# F-3.2 3-D references. SUM is a test-runner builtin (WP-05 owns the real one).
sheet Sheet1
sheet Sheet2
sheet Sheet3

set Sheet1!A1 1
set Sheet2!A1 2
set Sheet3!A1 3

set Sheet1!B1 =SUM(Sheet1:Sheet3!A1)
expect Sheet1!B1 6

set Sheet2!B1 =SUM(Sheet3:Sheet1!A1)
expect Sheet2!B1 6

set Sheet1!C1 =Sheet99!A1
expect Sheet1!C1 #REF!
