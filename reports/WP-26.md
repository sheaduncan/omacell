# Report — WP-26: Printing and PDF export

## Plan (written before coding)
- Files/modules to create:
  - `crates/core/src/print.rs` — `PageSetup`, paper sizes, pagination (`PageBox`)
  - `crates/io/src/pdf.rs` — PDF writer (`pdf-writer` + optional `ttf-parser` embed)
  - `crates/io/src/xlsx/print.rs` — parse/write `pageSetup`/`pageMargins`/`printOptions`/`headerFooter`/`rowBreaks`/`colBreaks`
  - CLI: `omacell convert in.xlsx out.pdf`; `file.print`
  - GUI: print-preview page boxes from the same paginator
  - Tests: pagination corpus; golden PDF text/geometry; `pdftotext`/`mutool` if present
- Interfaces:
  - `omacell_core::print::{PageSetup, PaperSize, paginate, PageBox}`
  - `omacell_io::pdf::{write_pdf, PdfOptions}`
  - `file.print` / convert-to-`.pdf`
- Tests first:
  - Letter vs A4 page counts; fit-to-1×1 vs 100% scale; manual row breaks
  - Print-area clips; hidden rows skipped
  - PDF page count matches paginator; extracted text includes A1 values
  - `/FontFile2` present when a TTF is supplied
- Decisions:
  - Same grid + chart `Scene` ops drawn into PDF content (print equals screen)
  - Existing `WorksheetExtras.print_xml` still wins on write for corpus byte-identity; modeled `PageSetup` is used when extras are empty
  - Standard Helvetica for the no-font path; embed TTF via `ttf-parser` when `ui_font_path` or an explicit face is given
  - CUPS: `file.print` writes a temp PDF and execs `lp` when a printer name is set; no printer → PDF export only
  - Fit-to-pages scale is `floor(100 * min(pages_w * usable_w / content_w, pages_h * usable_h / content_h))` percent, clamped 10–400
- Open questions at planning time:
  1. Exact Excel fit-to rounding on mixed hidden rows — corpus will lock our formula; differences vs Excel go in Open questions.

## What was built
- `omacell_core::print`: `PaperSize` (Letter/Legal/A4/A3/Tabloid), `Orientation`, `Margins` (Excel 0.75/0.3 in defaults), `PageSetup` on `Sheet`, `paginate` → `PageBox`, `expand_header` (`&P&N&A&F&D`). Hidden rows contribute 0 px via geometry. Title rows/cols of 0 no longer steal one row/col of usable space.
- `.xlsx` mapping: parse captured print fragments into `PageSetup`; extras-win write for L3 corpus; modeled XML when extras are empty. `_xlnm.Print_Area` / `_xlnm.Print_Titles` defined names are applied on read and emitted on write when missing from the registry.
- `omacell_io::pdf::write_pdf`: per-sheet pagination, grid + number-formatted cells, headers/footers, chart `Scene` ops, URI link annotations. Helvetica standard-14, or Type0/CIDFontType2 + `/FontFile2` when a TTF is supplied.
- CLI: `omacell convert in.xlsx out.pdf`; `file.export` to `.pdf`; `file.print` returns page boxes and `lpstat -a` printers; with `path` writes PDF; with `printer` runs `lp -d`.
- GUI: Ctrl+P / `file.print` toggles a print-preview overlay of page boxes on the grid (same `paginate`).
- Tests: `crates/core/tests/print.rs` (8 cases); `crates/io/tests/pdf.rs` (page count, extracted `Hello`, Letter MediaBox, Helvetica vs `/FontFile2`, xlsx round-trip, `pdftotext` when present). `just check` green.

## Interfaces exposed (for dependents)

- Command `file.print` `{ path?, printer? }` (CLI file adapter, same pattern as `file.export`). Empty args = preview JSON (`pages`, `printers`).
- Convert destination `.pdf` is a first-class export format.

## Deviations from the spec or the package (with reasons)
- `file.print` stays in `DEFERRED_COMMANDS` for UI keymap tests that do not compose the CLI file adapter, matching `file.open` / `file.save` (WP-13). The CLI composition root registers the live command.
- CUPS device chooser is the `printers` array from `lpstat -a` plus the `printer` argument, not a native GUI dialog. Ctrl+P toggles preview; a printer name is passed as command args.
- Header `&D` is the fixed civil date `1970-01-01` so PDF bytes stay deterministic.
- `mutool` is not installed here; the test skips cleanly. `pdftotext` 26.08.0 opened the golden PDF with empty stderr.
- Histogram / exotic DrawingML remain WP-25 policy; print draws the same `Scene`.

## Measurements
- Pagination: Letter portrait, default 0.75 in margins, 20 px rows → 45 rows/page (684 pt / 15 pt). Fit-to 1×1 uses `floor(100 * min(sx, sy))` clamped 10–400.
- PDF: two-page 50-row seed, Helvetica, no `/FontFile2`. Embedded DejaVuSans when present writes `/FontFile2`. `pdftotext -layout` recovered `Hello` from A1.
- `just check` green. `cargo deny check` green (`pdf-writer` 0.12.1, `ttf-parser` 0.25.1, both pre-approved).

## Open questions / decisions needed
1. Excel fit-to with mixed hidden rows and `fitToHeight=0` (unlimited) is not modeled; 0 is treated as 1. Lock further cases if a corpus vs Excel disagrees.
2. Print titles currently store a *count* from the print-area origin, not an arbitrary `$3:$4` band in the middle of the sheet.
3. Native GUI printer dialog vs palette JSON `{ "printer": "…" }` — WP-28 can add a chooser panel if needed.
