## What was built
- `omacell_core::print`: `PaperSize` (Letter/Legal/A4/A3/Tabloid), `Orientation`, `Margins` (Excel 0.75/0.3 in defaults), validated and undo-tracked `PageSetup` on `Sheet`, fallible bounded `paginate` → `PageBox`, and `expand_header` (`&P&N&A&F&D`). Hidden rows contribute 0 px via geometry. Width-only or height-only fit leaves the other axis unlimited; repeated-title dimensions are included in fit scaling.
- `.xlsx` mapping: parse captured print fragments into `PageSetup`; preserve L3 print XML and defined-name formulas only while they semantically match the model, otherwise regenerate them. Non-finite/negative margins are ignored, scale is clamped, and fit-to zero maps to unlimited. `_xlnm.Print_Area` / `_xlnm.Print_Titles` are applied on read and refreshed after edits.
- `.omc` mapping: sheet records carry modeled `PageSetup`; the reader also hydrates older OMC files that contain only preserved XLSX print extras/names, keeping XLSX→OMC→XLSX L2 stability.
- `omacell_io::pdf::write_pdf`: per-sheet pagination, repeated title rows and columns, optional row/column headings, grid + number-formatted cells, headers/footers, chart `Scene` ops, and correctly offset URI link annotations. Helvetica standard-14, or Type0/CIDFontType2 + `/FontFile2` when a TTF is supplied. Font reads, page counts, cell visits, and generated streams are bounded.
- CLI: `omacell convert in.xlsx out.pdf`; `file.export` to `.pdf`; `file.print` returns page boxes and `lpstat -a` printers; with `path` writes PDF; with `printer` validates the CUPS name, creates a mode-0600 exclusive spool file below `$XDG_RUNTIME_DIR/omacell/print`, runs `lp -d`, and removes the spool on both success and failure.
- GUI: Ctrl+P / `file.print` toggles a print-preview overlay that recomputes from the current workbook snapshot, so edits cannot leave stale page boxes.
- Tests: `crates/core/tests/print.rs` (11 cases); `crates/io/tests/pdf.rs` (10 cases); XLSX print parser and CLI spool unit regressions. Focused suites and workspace all-target compilation are green; full `just check` evidence is recorded below.

## Deviations from the spec or the package (with reasons)
- `file.print` is registered by the CLI composition root. The post-WP-27 integration audit removed it, `file.open`, and `file.save` from `DEFERRED_COMMANDS`; UI-only tests carry an explicit composition-root handoff and a CLI test verifies the live catalog.
- CUPS device chooser is the `printers` array from `lpstat -a` plus the `printer` argument, not a native GUI dialog. Ctrl+P toggles preview; a printer name is passed as command args.
- Header `&D` is the fixed civil date `1970-01-01` so PDF bytes stay deterministic.
- `mutool` is not installed here; the test skips cleanly. `pdftotext` 26.08.0 opened the golden PDF with empty stderr.
- Histogram / exotic DrawingML remain WP-25 policy; print draws the same `Scene`.

## Measurements
- Pagination: Letter portrait, default 0.75 in margins, 20 px rows → 45 rows/page (684 pt / 15 pt). Fit-to uses `floor(100 * min(sx, sy))` clamped 10–400; a missing fit axis is unlimited rather than one page.
- PDF: two-page 50-row seed, Helvetica, no `/FontFile2`. Embedded DejaVuSans when present writes `/FontFile2`. `pdftotext -layout` recovered `Hello` from A1.
- `just check` green. `cargo deny check` green (`pdf-writer` 0.12.1, `ttf-parser` 0.25.1, both pre-approved).
