## What was built

WP-17 now supplies the complete daily-editing command surface with exact direct undo and exact changeset reversal.

- Structure: insert/delete cells, rows, and columns; sheet remove/reorder; hide/unhide; row/column size and auto-fit; grouping, outline level, collapse/expand; merge/merge-across/unmerge. Structural operations shift side records and rewrite workbook formulas, including cross-sheet move retargeting and `#REF!` results.
- Fill: copy, formats-only, linear, growth, date, weekday, month, year, custom list, and down/right/up/left directions.
- Clipboard: portable values/formulas/styles/number formats/protection flags/rich-text runs, column widths, notes, threaded comments, hyperlinks, and contained merges. Paste Special supports composable values/formulas/formats/number-formats/column-widths/transpose/skip-blanks/arithmetic/paste-link options. Cut and drag move work across sheets; `edit.move { copy: true }` is atomic Ctrl+drag copy.
- Records and protection: legacy notes, threaded comments/replies/resolve, hyperlinks, sheet/workbook protection, allowed actions, protected ranges, and locked/hidden cell flags.
- Data tools: delimited or fixed-width Text to Columns with per-column types, Remove Duplicates with selected key columns/header handling and side-record compaction, and consolidate-by-position.
- Frontend ids: yank/delete/change/clear-row/repeat, AutoSum, date/time insertion, copy formula/value above, formatting presets/toggles/borders, and format-panel query are registered with typed schemas.
- Exact reversal: all changeset-eligible mutations receive a bounded logical `edit.restore` inverse containing only changed cells, changed sheet metadata, sheet membership/order/active state, and workbook protection. Direct undo uses exact core deltas, including whether an axis size was explicit or inherited.
- `.xlsx`: real threaded-comment and person parts are read/written; replies and resolved state survive. Workbook/sheet protection, allowed actions, protected ranges, row and column outline/collapse, hyperlinks, notes, and merges round-trip together. `.omc` also carries workbook protection.

## Deviations from the spec or the package (with reasons)

- Flash Fill was assigned to and completed by WP-18; `edit.flashfill` is registered with a deterministic supported-pattern subset.
- Consolidation by category remains tier 1; WP-17 implements the required consolidate-by-position path.
- The command bus uses deterministic built-in text-size estimates; GUI frontends can call the core auto-fit APIs with their real glyph measurement callback.
- The workbook model does not expose threaded-comment timestamps or stable source GUIDs, so generated OOXML uses deterministic valid GUIDs and timestamps while preserving the modeled author/text/reply/resolved semantics.

## RFC (frozen contract changes)

**Approved by merge.** WP-17 necessarily adds the daily-editing API and command
surface frozen at Gate G0.

- Core: outline/collapse geometry APIs; validated workbook reorder/protection/outline methods; portable clipboard, Text to Columns, protected-range, workbook-protection, and exact logical sheet-state types; exact undo delta fields/variants.
- Existing public structs gain fields: `PasteSpecial`, `ClipCell`, `ProtectionState`, and `Comment`. Serde defaults preserve wire compatibility; Rust dependents constructing these with exhaustive literals must add the new fields or use `..Default::default()` where available.
- Commands: the ids listed above become public typed commands. `sheet.remove` changes from internal to public. Existing WP-17 draft schemas are extended compatibly with optional/defaulted fields such as composable Paste Special, `edit.move.copy`, protection allowed actions, selected duplicate columns, and full Text to Columns plans.
- Migration: command callers may continue using legacy Paste Special strings; new callers should use the composable option object. Model/agent callers continue to mutate only through changesets. No raw mutable workbook API was added.
- Alternative rejected: deferring inverses or threaded-comment writing would leave WP-17 commands unusable by agents or silently lose L2 data, violating the package and frozen mutation policy.
