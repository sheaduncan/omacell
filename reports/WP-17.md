## What was built
Structural edits, fill, clipboard, comments/notes, hyperlinks, protection, text-to-columns, and remove-duplicates as core ops plus bus commands.

- `crates/core/src/ops.rs` — insert/delete rows/cols/cells with sheet-aware formula rewrite (`=A3` → `=A4`, deleted refs → `#REF!`), fill series (linear/growth/date/weekday/month/year), paste-special, atomic move, merge/merge-across, Excel XOR hash (`password` → `0x83AF`)
- Geometry outline levels + collapsed; xlsx `outlineLevel` round-trip
- Threaded comments remain lossless in memory; `.xlsx` save rejects them until real threaded-comment parts can be emitted, rather than silently downgrading replies/resolution state to legacy notes
- `omacell_bus::register_edit_commands` — `edit.insert`/`delcells`/`copy`/`cut`/`paste`/`pastespecial`/`move`/`fillselection`/`filldown`/`fillright`/`note`/`hyperlink`/`texttocolumns`/`clearcell`/`group`/`ungroup`, `range.merge`/`mergeacross`/`unmerge`/`removeduplicates`, `view.hide*`/`unhide*`, `sheet.protect`/`reorder`; `sheet.remove` promoted to public
- Review fixes add source-to-destination formula deltas for paste, workbook-wide cut retargeting, band-limited insert-cell rewrites, full-style clipboard payloads, duplicate-row compaction, grid bounds checks, exact legacy-hash serialization, column ungrouping, and undo-tracked row/column hide and size changes
- Tests: `crates/core/tests/ops.rs` (19), `crates/bus/tests/edit.rs` (8)

## Deviations from the spec or the package (with reasons)
- Threaded comments are not yet written as `threadedComment`/person parts. Save fails explicitly instead of silently converting them to legacy notes, because that conversion loses replies and resolution state.
- Category consolidate is tier 1; only consolidate-by-position is implemented.
- Flash Fill stays WP-18 (`edit.flashfill` remains deferred).
- Format toggles (`format.bold`, …) stay deferred; they need style intern helpers beyond this package's structure/clipboard work.
- Cross-sheet cut/move and fill are rejected explicitly; same-sheet cut/move is atomic and retargets dependents.
- WP-17 mutating commands, including promoted `sheet.remove`, are temporarily `changeset_eligible: false`. Their handlers do not yet emit exact inverse commands; advertising them as eligible allowed a changeset apply to mutate the workbook and then fail lifecycle validation. This is a merge blocker, not a completed deviation.
- Exact direct undo is still missing for merges, outline levels/collapse, notes/comments/hyperlinks, protection, reorder, and several side-table shifts. Row/column hidden and size changes are now undo tracked.
- Up/left fill, custom lists, fixed-width/per-column-type Text to Columns, threaded comment edit/reply/resolve commands, workbook protection, allowed-action/cell-lock commands, clear variants, row/column size and collapse commands, and the public consolidate command remain unimplemented.
- The required structural TSV corpus, fill/paste matrix corpus, and per-command `proptest` undo identities are not present. Unit regression tests are not a substitute for those acceptance artifacts.
