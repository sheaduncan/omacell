  - `omacell_core::ops::{excel_xor_hash, FillMode, PasteSpecial, insert_cells, fill_series, …}`
  - Commands: `sheet.remove` (public), `sheet.reorder`, `edit.insert`, `edit.delcells`, `edit.copy`/`cut`/`paste`/`pastespecial`/`move`, `edit.fillselection`/`filldown`/`fillright`, `range.merge`/`mergeacross`/`unmerge`, `view.hide*`/`unhide*`, `edit.group`/`ungroup`, `edit.note`, `edit.hyperlink`, `sheet.protect`, `edit.texttocolumns`, `range.removeduplicates`, `range.consolidate`, format toggles
  - Atomic `edit.move` for GUI drag-drop (not cut+paste tasks)
- Tests and corpora to write first:
  - Structure: insert/delete row/col rewrites `=A3` → `=A4` / `#REF!`
  - Paste Special matrix (values, formulas, transpose, skip blanks, add)
  - Fill series (linear, growth, weekday)
  - Protection XOR hash known vector
  - `edit.undo` identity after each command
- Items the package says to "decide and document":
  - Clipboard payload is JSON on the command result (`edit.copy`); the bus does not hold clipboard state. `edit.paste` takes that payload. `edit.move` is one command.
  - Legacy sheet-protection hash is the Excel XOR algorithm (`password` attribute); documented as not security (spec §12.3).
  - `sheet.remove` is promoted from Internal to Public (WP-07a inverse stays the same handler).
  - Flash Fill stays WP-18 (`edit.flashfill` remains deferred).
  - Category consolidate is tier 1; this package implements consolidate-by-position.
- Open questions at planning time:
  1. Insert-*cells* (not whole rows) formula adjustment vs Excel when a ref only partially overlaps the shifted band — corpus locks our rule: refs wholly in the shifted columns/rows adjust; others stay.
  2. Exact published XOR hash vectors vs our implementation — we record the algorithm and a golden for `"password"`.

## What was built
Structural edits, fill, clipboard, comments/notes, hyperlinks, protection, text-to-columns, and remove-duplicates as core ops plus bus commands.

- `crates/core/src/ops.rs` — insert/delete rows/cols/cells with sheet-aware formula rewrite (`=A3` → `=A4`, deleted refs → `#REF!`), fill series (linear/growth/date/weekday/month/year), paste-special, atomic move, merge/merge-across, Excel XOR hash (`password` → `0x83AF`)
- Geometry outline levels + collapsed; xlsx `outlineLevel` round-trip
- Threaded comments write through `comments.xml` (reload as legacy notes)
- `omacell_bus::register_edit_commands` — `edit.insert`/`delcells`/`copy`/`cut`/`paste`/`pastespecial`/`move`/`fillselection`/`filldown`/`fillright`/`note`/`hyperlink`/`texttocolumns`/`clearcell`/`group`/`ungroup`, `range.merge`/`mergeacross`/`unmerge`/`removeduplicates`, `view.hide*`/`unhide*`, `sheet.protect`/`reorder`; `sheet.remove` promoted to public
- Tests: `crates/core/tests/ops.rs` (14), `crates/bus/tests/edit.rs` (5)

- Commands (register with `register_edit_commands`): see list above. Clipboard is JSON on `edit.copy` result; `edit.paste` takes `payload`; `edit.move` is the atomic drag-drop op (do not compose cut+paste tasks).
- WP-17 ids remain in `DEFERRED_COMMANDS` for UI keymap tests that do not compose the CLI registry (same pattern as `file.open`).

## Deviations from the spec or the package (with reasons)
- Threaded comments are written as legacy `comments.xml` and reload as notes. Dedicated `threadedComment` parts stay a later fidelity pass.
- Category consolidate is tier 1; only consolidate-by-position is implemented.
- Flash Fill stays WP-18 (`edit.flashfill` remains deferred).
- Format toggles (`format.bold`, …) stay deferred; they need style intern helpers beyond this package's structure/clipboard work.
- Command inverses for large inserts rely on `edit.undo` / workbook deltas rather than a full changeset inverse payload.
