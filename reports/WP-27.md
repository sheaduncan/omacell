## What was built

ODS read/write, JSON array-of-objects import/export with dotted flattening and a jq-style pointer, Parquet/Arrow read, HTML/Markdown file import (reusing WP-08 clipboard parsers) plus export, and a LibreOffice `.xls`→`.xlsx` bridge. `xlsx::peer_lock_blocks` refuses open when a Calc/foreign `.~lock.*#` is present; ODS/JSON/HTML/MD save uses the same lock path.

## Deviations from the spec or the package (with reasons)

- **Parquet is read-only** as the package specified.
- **ODS write is v1 basic:** modeled values/formulas/merges/names and a small style subset. Full LO themes, page setup, and charts are not rewritten.
- **JSON `--jq` is a convert CLI flag**, not a `file.open` schema field (WP-07a freeze). `file.open` on `.json` uses the document root.
- **`.xls` is never written.** Bridge converts to xlsx and opens that.
- **Number formats in ODS v1** are not a full `number:number-style` mapper; dates become Excel serials.
