- Items the package says to "decide and document" and the decision taken:
  - **Index origin:** `row`/`col` are 0-based. A1 `A1` is `(0, 0)`; R1C1 `R1C1` is the same cell. Printers add 1. `MAX_ROWS`/`MAX_COLS` are counts (valid indices `0..MAX_*`).
  - **`CellRef.sheet`:** a resolved `SheetId` (`u32` newtype). Parsers return names in `SheetSpec`; workbook-scoped name → id is WP-02. `CellRef.sheet` is `None` for sheet-local refs.
  - **R1C1 storage:** `CellRef` stores absolute grid indices plus abs flags, as specified. Relative R1C1 (`R[-1]C[2]`) is resolved/printed against an explicit base cell. Offsets that land outside the grid are `#REF!`.
  - **Whole-row/column / 3-D:** `RangeRef` carries `whole_row` / `whole_col` so `A:A` does not print as `A1:A1048576`, plus `sheet` / `sheet_end` for `Sheet1:Sheet3!A1`.
  - **`ERROR.TYPE`:** Microsoft’s documented table (1–8 for the classic errors + `#GETTING_DATA`; anything else → `#N/A`, represented as `None`). Exceljet’s 9/11/14 for `#SPILL!`/`#BLOCKED!`/`#CALC!` is recorded as an open question, not encoded.
  - **`schemars`:** WP sketch says `schemars::RootSchema` (0.8). That type was removed in schemars 1. Freeze `arg_schema: schemars::Schema` on schemars 1.x so later command/config packages are not stuck on 0.8. Deviation noted below after implementation.
  - **JSON of `Value::Number`:** finite `f64` as a JSON number (serde_json shortest). `NaN`/`Inf` are valid in-memory IEEE values (F-2.1) but are not JSON-portable; serde tests use finite values.
  - **`Event`:** `#[non_exhaustive]` because the WP lists `…`. Other enums are exhaustive so adding a variant after G0 is a visible freeze break.
  - **`smallvec`:** allowed; used for gradient stops (typically 2). Not used to replace `Vec<CommandCall>` (WP sketch freezes `Vec`).
  - **Style `Eq`/`Hash`:** `f64` fields (`font.size_pt`, gradient/theme tints) compare by `to_bits` so WP-02 can intern by value.

Index origin: 0-based. `CellRef.sheet` is a resolved id; full parsers return names in `SheetSpec`, while cell-only parsers reject sheet-qualified input. R1C1 relatives resolve against a validated base cell. Invalid `CellRef`/`Array2D` wire values are rejected.

Changeset lifecycle: proposed changesets have an empty inverse list. WP-07 computes inverses from trusted workbook state before marking them applied; applied/reverted non-empty changesets require a non-empty inverse list. Agent-provided inverses are never trusted.

## Deviations from the spec or the package (with reasons)

- **`CommandDescriptor.arg_schema` is `schemars::Schema`, not `RootSchema`.** schemars 1.2.2 removed `RootSchema`. Freezing 1.x avoids pinning later command/config packages to 0.8.
- **`Event` includes F-10.1 `WorkbookOpened` / `BeforeSave` and changeset applied/reverted**, in addition to the WP sketch list, and is `#[non_exhaustive]` because the WP writes `…`.
- **`ParsedRef` / `SheetSpec` / `RefKind`** are extra types so A1/R1C1 parsers can return sheet *names* without a workbook id map (WP-02).
- **`locale` is identity + `en-US` separators only.** Full LCID tables are WP-06.
- **JSON `Value::Number` is not bit-exact** for arbitrary `f64` (serde_json shortest). In-memory IEEE values including NaN/Inf are allowed. Serde tests use integer-valued floats plus a few exact decimals.
- **`UndoUnitId`** sits next to the `UndoUnit` marker so WP-02 has a handle type.
