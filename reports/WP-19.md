## What was built

WP-19 lands the deterministic audit, find/replace, Go To Special, error explanations, Evaluate-Formula traces, and a diagnostic bundle for WP-21.

- **Audit** (`crates/core/src/audit.rs`): stable finding ids for hardcoded constants, inconsistent R1C1 formulas, ranges that stop short of the data region, unused defined names, circular references, external links (formulas and hyperlinks), volatile formulas, and merged cells inside tables. Output is `AuditReport { schema: 1, findings }` sorted by `(id, sheet, ref)`.
- **Explain / trace**: `#NAME?` names the unknown token; `#REF!` names the deleted range; `#SPILL!` names the blocker; `#DIV/0!` names the divisor. `eval_steps` walks the AST children-first with intermediate values. `precedents_of` / `dependents_of` wrap `DepGraph`.
- **Find** (`crates/core/src/find.rs`): values or formulas, whole-cell, case, regex (`regex` crate, 256-char / 1 MiB compile cap, 250 ms scan budget). Preview count equals applied count. Go To by A1/name; Go To Special for blanks, constants by type, formulas, errors, visible cells, CF, and validation.
- **Bus**: `register_audit_commands`. UI already owns `edit.find` / `edit.replace` / `nav.goto` as dialog openers, so the engine commands are `edit.findall`, `edit.replaceall`, `nav.address`, plus `nav.gotospecial`, `audit.run`, `audit.diagnose`, `formula.explain` / `trace` / `precedents` / `dependents`.
- **CLI**: `omacell audit <book> --json` (stub removed). Schema: `docs/schemas/audit.schema.json`.
- **WP-22 hook**: `redact_identity` is a no-op until redaction lands.

Evidence: `crates/core/tests/audit.rs`, `crates/bus/tests/audit.rs`, `crates/cli/tests/subcommands.rs::audit_json_matches_schema_shape`, `tests/corpus/audit/checks.tsv`.

## Deviations from the spec or the package (with reasons)

- Engine find/replace/goto command ids are `edit.findall`, `edit.replaceall`, and `nav.address` so they do not collide with WP-14 UI dialog commands `edit.find`, `edit.replace`, and `nav.goto`.
- Hard-coded constant check flags any numeric literal inside a non-trivial formula (including `+1`). The seeded corpus lists those cells.
- Transitive precedent expansion caps range walk at 256 rows × 32 columns per precedent to bound memory.
- Regex “timeout” is a compile-size cap plus a 250 ms scan budget; the `regex` crate itself is linear-time.
