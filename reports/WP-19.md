## What was built

WP-19 lands the deterministic audit, find/replace, Go To Special, error explanations, Evaluate-Formula traces, and a diagnostic bundle for WP-21.

- **Audit** (`crates/core/src/audit.rs`): stable finding ids for hardcoded constants, contiguous row/column R1C1 anomalies, ranges that stop short in the referenced column, scope-aware unused names, distinct circular SCCs, external links (formulas and hyperlinks), volatile-function counts, and merged cells inside tables. Output is the bounded `AuditReport { schema: 1, findings, truncated }`, sorted by `(id, sheet, ref)`.
- **Explain / trace**: `#NAME?` names the unknown token; `#REF!` names the deleted range; `#SPILL!` names the blocker; `#DIV/0!` names the divisor. `eval_steps` walks the AST children-first with intermediate values. `precedents_of` / `dependents_of` wrap `DepGraph`.
- **Find** (`crates/core/src/find.rs`): values or formulas, whole-cell, Unicode-safe case-insensitive literals, anchored whole-cell regex, bounded result sets, sheet/workbook scope, and exact replacement previews. Empty queries and unknown sheets fail explicitly. Go To resolves qualified addresses and local/workbook names; Go To Special covers blanks, constants by type, formulas by result type, errors, visible cells, dependency selections, CF, and validation.
- **Bus**: `register_audit_commands`. UI already owns `edit.find` / `edit.replace` / `nav.goto` as dialog openers, so the engine commands are `edit.findall`, query-only `edit.replacepreview`, mutating `edit.replaceall`, `nav.address`, plus `nav.gotospecial`, `audit.run`, `audit.diagnose`, and formula explain/trace/dependency queries. Cell lists are sheet-qualified; replacement provides dirty cells, exact undo, and dependency-graph rebuilds for formula replacements.
- **CLI**: `omacell audit <book> --json` (stub removed). Schema: `docs/schemas/audit.schema.json`.
- **WP-22 hook**: `redact_identity` is a no-op until redaction lands.

Evidence: `crates/core/tests/audit.rs`, `crates/bus/tests/audit.rs`, `crates/cli/tests/subcommands.rs::audit_json_validates_against_committed_schema`, `tests/corpus/audit/{checks.tsv,explain.tsv}`.

## Deviations from the spec or the package (with reasons)

- Engine find/replace/goto command ids are `edit.findall`, `edit.replacepreview`, `edit.replaceall`, and `nav.address` so they do not collide with WP-14 UI dialog commands `edit.find`, `edit.replace`, and `nav.goto`.
- Hard-coded constant check flags any numeric literal inside a non-trivial formula (including `+1`). The seeded corpus lists those cells.
- Transitive precedent expansion caps range walk at 256 rows × 32 columns per precedent to bound memory.
- Regex “timeout” is a compile-size cap plus a 250 ms scan budget; the `regex` crate itself is linear-time.
- `visible` operates over stored cells; blank selection operates over the used rectangle. Both avoid materializing the full Excel grid.

## RFC (only if a frozen contract changed)

### Requested changes

- Add the public `audit` and `find` core modules and the types/functions listed above; add bounded `AuditReport.truncated`, `DepGraph::circular_components`, and read-only `UndoLog::history`.
- Add the WP-19 public commands to the frozen command catalog. Replacement uses separate query-only `edit.replacepreview` and mutating `edit.replaceall` contracts; Go To Special uses an enum instead of an open string and returns sheet-qualified cells.
- Add the version-1 `audit.schema.json` wire contract. It requires `schema`, `findings`, and `truncated`; findings reject unknown fields and carry optional typed fix commands.

### Why

WP-19 must expose deterministic audit/navigation services to CLI, UI, and later agent packages. Separate preview/mutation contracts prevent a command classified as mutating from silently acting as a query, while typed kinds and qualified locations remove ambiguity before these schemas become permanent. The bounded report/result APIs prevent untrusted workbooks from forcing unbounded response allocation.

### Migration and compatibility

- These commands and the audit schema first land in this PR, so no released WP-19 caller needs migration. Callers built against the original PR tip should rename replacement field `replace` to `replacement`, remove `apply`, use `edit.replacepreview` for previews, and consume qualified cell strings.
- Command consumers should regenerate `commands.json`. The IPC v1 envelope is unchanged.
- `AuditReport` construction must provide `truncated`; deserializers should reject older provisional WP-19 output that omitted the required field rather than guessing whether it was complete.

### Alternatives considered

- Keeping one mutating command with `apply: false` was rejected because its command classification, changeset preflight, and undo/recalc behavior were inconsistent.
- Returning bare A1 addresses was rejected because workbook-scope results are ambiguous.
- Leaving Go To Special as a free string was rejected because invalid kinds would not be discoverable or schema-validatable.
- Unbounded findings and cell lists were rejected because workbook content is untrusted input.
