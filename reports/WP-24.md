## What was built

Pivot tables, Goal Seek, and a selection statistics API, with `.xlsx` cache/table parts so Excel and LibreOffice see a live pivot.

- `crates/core/src/pivot.rs`: row/column/value/filter fields; SUM/COUNT/AVERAGE/MIN/MAX/COUNTA/DISTINCT COUNT/STDEV/VAR; show-as % of total/row/column, running total, difference from; date grouping (days/months/quarters/years) and numeric bins; compact/outline/tabular; subtotals and grand totals; managed output region with bold header/total styles.
- `crates/core/src/whatif.rs`: Goal Seek, secant with bisection fallback, 100 iterations / 1e-6 default, non-convergence reported without error. Iteration does not flood the undo log; the last trial is one cell delta.
- `crates/core/src/stats.rs`: count, countA, sum, mean, sample stdev/var, min/max/median, Sturges histogram (1–20 bins).
- `crates/core/src/workbook.rs`: `add_pivot` / `refresh_pivot` / `refresh_pivot_from_cache` / `remove_pivot` / `import_pivot` / `restore_pivot`; `pivot.readonly` on user cell edits.
- `crates/bus/src/analysis.rs`: public commands registered in CLI/GUI/TUI/UI composition roots.
- `crates/io/src/xlsx/pivot.rs`: write and read `pivotCacheDefinition`, `pivotCacheRecords`, and `pivotTable` parts; cache records used for display when the source range is missing.

Key tests: `crates/core/tests/pivot.rs`, `crates/bus/tests/analysis.rs`, `crates/io/tests/pivot_roundtrip.rs`.

## Deviations from the spec or the package (with reasons)

- Data Tables and Scenario Manager remain deferred (package text).
- Compact multi-field row labels are joined with ` | ` rather than Excel-style indent.
- Show-as percentages are stored as 0–100 numbers in the snapshot, not percent-formatted 0–1 values.
- Distinct Count is computed natively; OOXML export uses `subtotal="count"` with a Distinct-count caption because Excel's distinct-count extension is not modeled.
- `pivot.refresh` is not changeset-eligible; `edit.undo` still reverts via cell + pivot deltas.
