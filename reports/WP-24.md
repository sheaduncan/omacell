## What was built

Pivot tables, Goal Seek, and a selection statistics API, with live `.xlsx` pivot cache/table parts and a native `.omc` representation.

- `crates/core/src/pivot.rs`: reusable columnar `PivotColumns` source; row/column/value/filter fields; SUM/COUNT/AVERAGE/MIN/MAX/COUNTA/DISTINCT COUNT/STDEV/VAR; all specified show-as modes; date/numeric grouping; compact/outline/tabular layouts; subtotals/grand totals; deterministic numeric/date ordering; fractional percentage values with percentage styles.
- Pivot safety: definitions and fields are validated before mutation; output refuses source/merge/table/other-pivot/occupied-cell overlap and grid overflow; cache/materialized output is capped at 1,000,000 cells; aggregation rejects non-finite results.
- Managed regions: ordinary value, style, note, comment, hyperlink, merge, sort, table, and structural-edit paths cannot mutate pivot output. Create/refresh/remove and Goal Seek each commit as one undo unit.
- `crates/core/src/whatif.rs`: validated formula target and mutable input, exact iteration cap, secant with bisection fallback, one target evaluation per trial, style/flags preserved, finite non-convergence result.
- `crates/core/src/stats.rs`: count, countA, sum, mean, sample stdev/var, min/max/median, and a Sturges histogram (1–20 bins), with unknown-sheet validation.
- `crates/io/src/xlsx/pivot.rs`: bounded read/write of cache definitions, shared items, cache records, and pivot tables; resolves Excel/LibreOffice `<x>` shared-item indexes; retains filters and subtotal choices; uses cached records if the source sheet is missing. Workbook XML emits `calcPr` before `pivotCaches` per schema order.
- `crates/io/src/omc`: `pivot` records retain the full native model and stable id. The round-trip test also found and fixed a pre-existing parser bug that reused the initial `Sheet1` for a second sheet.
- `crates/bus/src/analysis.rs`: public create/refresh/remove, Goal Seek, and statistics commands, including dry-run validation and managed-region enforcement through ordinary edit commands.

## Deviations from the spec or package

- Data Tables and Scenario Manager remain deferred as the package specifies.
- Compact multi-field row labels use ` | ` instead of Excel-style hierarchical indentation.
- Distinct Count is computed natively; OOXML export currently uses `subtotal="count"` with a Distinct-count caption instead of Excel's extended metadata.
- Unsupported pivot extensions/calculated fields are not retained when a supported pivot is regenerated.
- Row/column insertion/deletion and cell shifts are conservatively rejected on any sheet used by a pivot until source/output reference rewriting is implemented.
- `pivot.refresh` is not changeset-eligible; ordinary `edit.undo` still reverts the cell and registry deltas atomically.

The fidelity and structural-edit items have a bounded follow-up in `docs/build/wp/WP-24a-pivot-fidelity.md` and are recorded in `docs/compat/known-differences.md`.
