# Work-package reports

Each package writes `reports/WP-NN.md` from
[`docs/build/templates/wp-report.md`](../docs/build/templates/wp-report.md).
The *Interfaces exposed* section is the handoff to dependents.

Start with [WP-00](WP-00.md). Then WP-S1, WP-S2, and WP-01 may run concurrently.

The current cross-package status, completed pre-WP-28 queue, and remaining
WP-28/human-owned release gates are recorded in the
[1 September integration audit](integration-audit-2026-09-01.md).
