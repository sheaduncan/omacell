# Work-package reports

Each package writes `reports/WP-NN.md` from
[`docs/build/templates/wp-report.md`](../docs/build/templates/wp-report.md).
The *Interfaces exposed* section is the handoff to dependents.

Start with [WP-00](WP-00.md). Then WP-S1, WP-S2, and WP-01 may run concurrently.

The current cross-package status, completed pre-WP-28 and WP-28 technical
queues, and remaining human-owned release gates are recorded in the
[1 September integration audit](integration-audit-2026-09-01.md).

The independent whole-repository findings and their live PR-by-PR remediation
status are recorded in the
[2 September repository review](review-2026-09-02.md). Review-driven fixes
must update its remediation ledger before merge.
