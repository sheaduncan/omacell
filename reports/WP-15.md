## What was built

A ratatui front-end over the WP-14 session and WP-13 composition root. `omacell --tui [file]` loads one watched `ConfigStore`, registers file/theme/UI commands, starts SIGUSR1 + in-process IPC, and enters an alternate-screen loop. Tests drive the same `Tui::draw` / `Tui::step_key` path through `TestBackend` (no TTY, no second config load).

The grid is virtualized: only the visible parts of freeze panes plus the visible `Viewport` window are visited, so even a freeze edge at row 1,048,576 paints like a small sheet. Chrome is ANSI-indexed so Omarchy's terminal palette applies; `#rrggbb` from `LoadedConfig.theme.roles["references.N"]` is emitted as RGB only when `[tui] truecolor` is `on` or `auto` with `COLORTERM=truecolor|24bit`. Formula-bar references, overflow into empty neighbors, stale hatching, spill-region underlines, type-aware alignment, locale/date-system-aware number formats, workbook font/fill styles, frozen-pane separators, compact chrome below `[layout] compact_below_width`, the command palette, and docked panels (find/goto/keys/format/changeset) are rendered.

Review hardening added exact post-layout mouse hit-testing (including visibly retained Ctrl-add areas and drag), wheel/horizontal scrolling, Ctrl-wheel zoom, configured bottom sheet tabs, modal command-line and typed palette arguments, guarded dirty-workbook quit, saved sheet-view hydration, hidden-sheet navigation, recoverable invalid keymap reloads, and a copy-on-write render snapshot while the command bus is busy. The editing-integration follow-up captures rich copy/cut results for keyboard paste and enables Crossterm bracketed paste for bounded external TSV/CSV/HTML/Markdown text; the protocol is disabled with the other terminal modes on every return path. Cell, formula, sheet, panel, and status text is stripped of terminal control/bidi characters before rendering.

The 2026-09-02 space-entry follow-up makes the shared session insert U+0020
when a frontend supplies `KeyCode::Space` during an active edit. Outside edit
mode the same key still reaches the keymap, preserving the modal leader.

The 2026-09-04 terminal-edge follow-up negotiates Crossterm's keyboard
enhancement protocol and restores it with every other terminal mode. Active
editors consume bracketed paste locally; idle-grid paste keeps the existing
bounded one-command table mutation. Successful copy/cut/yank operations retain
the rich internal payload and queue at most 100 KiB of plain text for an OSC 52
host clipboard handoff. Split viewports now paint the leading and independently
scrolled panes with explicit terminal dividers, and conditional-format requests
remain separated across the off-screen gap. Panels convert configured CSS
pixels to terminal columns without the former 40-column cap, while overflow
stops before a cursor or split boundary. The audit's scroll-bound claim was
already fixed, shared key normalization lands with WP-14, and GTK scale probing
is process-cached with `OnceLock` rather than repeated on reload.
This remediation is tracked by review follow-up PR #169.

The WP-25 integration now paints modeled charts over their grid anchors. `auto`
uses Kitty for Kitty/Ghostty hints, accepts sixel/Kitty terminal-query answers
(including Foot's sixel capability), and falls back to ANSI-colored Unicode
braille. Automatic binary graphics fail closed under tmux and Herdr; an explicit
protocol remains available for configured passthrough. A bounded background
worker performs scene layout, PNG rasterization, and terminal-protocol encoding,
while the UI thread only consumes ready scenes/images. Theme/config reloads invalidate the bounded
cache and reconfigure graphics without resetting the edit session.

`UiSession::set_palette` was added so the TUI can type into and dismiss the retained palette model (WP-14 listed palette setters but only ranking helpers existed).

## Deviations from the spec or the package (with reasons)

- **No TTY → exit 1 (`tui.tty`)**, not a stub 3. CI `assert_cmd` pipes stdout, so this fail-closes instead of hanging in an alternate screen.
- **tmux/Herdr `auto` uses Unicode braille.** Binary graphics through a
  multiplexer require an explicit protocol so Omacell does not assume
  passthrough support.
- **Comments / format / sort-filter panels are connected.** The final pre-WP-28 audit replaced the historical placeholders with shared live panel bodies: `format.panel` consumes its bus query result, comments enumerate the current sheet snapshot, filter shows the active modeled criteria, and sort exposes the selected range plus the typed `range.sort` payload. GUI and TUI use the same toolkit-neutral model.
- **`UiSession::set_palette`** is a small additive WP-14 gap fill; keymap/config/theme parsing stay in their crates.
- **Long-lived frontend work was completed by WP-15a.** The retained TUI now
  submits mutations to the message-based single-writer runner and paints from
  immutable snapshots with bounded progress and cooperative cancellation.
- **Resolved terminal dependency advisory:** the TUI now uses ratatui 0.30.2, the obsolete transitive `paste` dependency and RUSTSEC-2024-0436 ignore are gone, and `deny.toml` no longer carries that exception.
- **OSC 52 uses Crossterm's optional `osc52` feature.** This adds no direct
  package dependency; its Base64 encoder was already present in the locked
  workspace graph. The 100 KiB raw-text cap prevents a large internal
  clipboard from becoming an unbounded terminal control sequence.
- **`tempfile` 3** (dev/bench) is already used by WP-13/14; isolated HOME/theme installs. `cargo deny check` is green.
