## What was built

A ratatui front-end over the WP-14 session and WP-13 composition root. `omacell --tui [file]` loads one watched `ConfigStore`, registers file/theme/UI commands, starts SIGUSR1 + in-process IPC, and enters an alternate-screen loop. Tests drive the same `Tui::draw` / `Tui::step_key` path through `TestBackend` (no TTY, no second config load).

The grid is virtualized: only the visible parts of freeze panes plus the visible `Viewport` window are visited, so even a freeze edge at row 1,048,576 paints like a small sheet. Chrome is ANSI-indexed so Omarchy's terminal palette applies; `#rrggbb` from `LoadedConfig.theme.roles["references.N"]` is emitted as RGB only when `[tui] truecolor` is `on` or `auto` with `COLORTERM=truecolor|24bit`. Formula-bar references, overflow into empty neighbors, stale hatching, spill-region underlines, type-aware alignment, locale/date-system-aware number formats, workbook font/fill styles, frozen-pane separators, compact chrome below `[layout] compact_below_width`, the command palette, and docked panels (find/goto/keys/format/changeset) are rendered.

Review hardening added exact post-layout mouse hit-testing (including visibly retained Ctrl-add areas and drag), wheel/horizontal scrolling, Ctrl-wheel zoom, configured bottom sheet tabs, modal command-line and typed palette arguments, guarded dirty-workbook quit, saved sheet-view hydration, hidden-sheet navigation, recoverable invalid keymap reloads, and a copy-on-write render snapshot while the command bus is busy. The editing-integration follow-up captures rich copy/cut results for keyboard paste and enables Crossterm bracketed paste for bounded external TSV/CSV/HTML/Markdown text; the protocol is disabled with the other terminal modes on every return path. Cell, formula, sheet, panel, and status text is stripped of terminal control/bidi characters before rendering.

`UiSession::set_palette` was added so the TUI can type into and dismiss the retained palette model (WP-14 listed palette setters but only ranking helpers existed).

## Deviations from the spec or the package (with reasons)

- **No TTY → exit 1 (`tui.tty`)**, not a stub 3. CI `assert_cmd` pipes stdout, so this fail-closes instead of hanging in an alternate screen.
- **Sixel/kitty graphics** are a named hook only. Chart widgets are WP-25.
- **Comments / format / sort-filter panels** render placeholders until WP-17/18/19 own the models.
- **`UiSession::set_palette`** is a small additive WP-14 gap fill; keymap/config/theme parsing stay in their crates.
- **Long-lived frontend work was completed by WP-15a.** The retained TUI now
  submits mutations to the message-based single-writer runner and paints from
  immutable snapshots with bounded progress and cooperative cancellation.
- **`paste` RUSTSEC-2024-0436** is ignored in `deny.toml`. It is transitive via pre-approved `ratatui` 0.29; 0.30 needs rustc 1.88 (above MSRV 1.85).
- **`tempfile` 3** (dev/bench) is already used by WP-13/14; isolated HOME/theme installs. `cargo deny check` is green.
