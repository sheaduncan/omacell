## What was built

The `omacell` binary is a clap tree over one composition root: one `Paths`, one retained `LoadOptions`, one `ConfigStore` (`load_with`, no watcher on one-shots), one `Bus` with WP-07a core commands plus `file.open`/`file.save`/`file.export` and `theme.reload`. File I/O stays in `omacell-io`; the CLI only registers adapters. SIGUSR1, IPC `--all`, and `theme.reload` share `ReloadHandle`, and direct reloads publish the same config events as filesystem reloads. External command effects run once after bus preflight; user dry-runs validate serialization without writing or changing sidecars.

The post-WP-16 focus integration makes bare `omacell ipc` select the focused
GUI/TUI instance, with the original newest-live discovery as a startup
fallback. Explicit `--socket` and broadcast `--all` behavior are unchanged.

## Deviations from the spec or the package (with reasons)

- **`signal-hook` 0.3** is not on the pre-approved list. It is the safe, unregistering SIGUSR1 adapter (`flag::register`); this crate forbids `unsafe`. License Apache-2.0/MIT. Drop when WP-15 can own the long-running loop.
- **`predicates` 3** is not on the pre-approved list. It supplies readable `assert_cmd` output matchers for the CLI contract suite. License Apache-2.0/MIT.
- **`tempfile` 3** is not on the pre-approved list. It supplies isolated managed homes/runtime directories for no-write, IPC, and symlink-containment tests. License Apache-2.0/MIT.
- **One-shot CLI uses `ConfigStore::load_with`**, not `load_and_watch_with`. Package default `live_reload = true` would otherwise start a notify watcher for `fn list`. Reload still works via `ReloadHandle`. TUI/GUI should call `load_and_watch_with`.
- **`--from-workbook`** is extra so `config show` can prove the settings overlay in a one-shot process. Query/set/eval/recalc always overlay the opened book.
- **`edit.undo` / `edit.redo`** remain legal on `omacell ipc` (WP-07b already allows execute).
- **Bare `omacell [file]` / `--tui`** exit 3 until WP-15/16. Spec F-10.5 launches GUI/TUI; those crates are empty.
