- Items the package says to "decide and document" and the decision taken:
  - **Packed slots, not a dense 65 536-slot array per block.** A dense `[CellSlot; 65536]` at 32 B/slot would be ~8 GB for 1M×20 (only one block-column is live, but every 256-row band still allocates 256 columns). Occupancy bitmap + packed `Vec<CellSlot>` (row-major set bits) meets “dense slot array plus occupancy bitmap”, the ≤ 64 B/cell budget, and sparse-sheet memory. Blocks live in `FxHashMap` keyed by block coordinate, as specified.
  - **`CellSlot` is 32 bytes** (`Value` 16 + `Option<FormulaId>` 8 + `StyleId` 4 + `CellFlags` 1 + pad). Notes, threaded comments, hyperlinks, merges live in side tables on `Sheet` (F-2.2 / WP text), not in the slot, so the numeric-cell budget is not charged for them.
  - **`FormulaId` is interned source text**, not an AST. The package's initial low-level shifts relocated slots only. WP-17 subsequently wrapped them with `core::ops` structural edits that rewrite formulas and side tables workbook-wide.
  - **CoW snapshot:** `Arc<Block>` pages + `Arc<Interners>`. `Workbook` is single-writer; `snapshot()` clones the block map (Arc bumps) so render can read during recalc (§11.5).
  - **Geometry:** sparse Fenwick of height/width *deltas* from the default (so empty sheets do not allocate 1M entries) plus a hidden set. `index_to_pixel` is O(log n); `pixel_to_index` binary-searches prefix sums (O(log² n), < 400 ops at 1M). Defaults: 20 px row, 64 px column.
  - **Intern recycle:** ids are stable while `refs > 0`. Undo deltas hold intern refs so undo cannot observe a recycled id. Style id 0 is `Style::default()` and is never freed.
  - **Sheet names:** ≤ 31 Unicode scalars, none of `[]:*?/\\`, non-empty, no leading/trailing `'`, unique ignoring ASCII/Unicode case. At least one sheet; the last *visible* sheet cannot be hidden or removed.
  - **Out-of-range shift:** insert that would push an occupied cell past `MAX_ROWS`/`MAX_COLS` is `addr.ref` (matches F-1.2).
  - **Counting allocator:** not a `#[global_allocator]` (workspace `unsafe_code = forbid`). `heap_bytes()` walks bitmaps, slot `capacity`, hashbrown bucket estimate, intern tables. Linux `/proc/self/statm` RSS is recorded as a secondary number for the 1M×20 case.
  - **New error codes** extend `error::codes`; WP-01 signatures and `docs/contracts.md` are not edited.
- Open questions at planning time:
  1. Should insert-row that would push data off the grid refuse (Excel) or drop overflowing cells? Plan: refuse with `addr.ref`.
  2. Excel defined-name grammar is larger than “not a cell ref” (single `R`/`C`, `\foo`, 255-char cap). Plan: enforce a conservative identifier + not-an-A1/R1C1-cell rule; expand in WP-03 if the formula parser needs more.
  3. Default row height / column width in pixels vs Excel’s point / character units — WP-06/UI may need a conversion. Plan: store pixels in geometry; 20 / 64 as engine defaults.

## What was built

In-memory workbook with the §11.3 storage layout, interners, Fenwick geometry, defined names, tables registry, and a memory-budgeted undo log. `Workbook` is single-writer; `snapshot()` is copy-on-write via `Arc<Block>` pages. Formula *source* is interned as `FormulaId`; there is no parser or AST (WP-03). `locale.rs` is unchanged.

Review hardening makes structural deletes exactly undoable by retaining deleted slots in the inverse delta, validates all shift arithmetic and side-table coordinates at grid boundaries, and removes discarded redo transactions from undo-budget accounting. The workbook and number-format packages share the canonical `date_system::DateSystem`; `workbook::DateSystem` remains a re-export for callers.

The 2026-09-03 audit follow-up replaces rich-string and array full-table
deduplication scans with private hash-to-candidate indexes. Exact payload
comparison remains authoritative after hashing, released ids are removed before
recycling, ordinary candidate buckets stay inline, and `heap_bytes()` includes
the index maps plus the rare spilled candidate vectors.

Key files:

- `crates/core/src/{workbook,sheet,storage,intern,geometry,names,tables,undo}.rs`
- `crates/core/src/lib.rs` — `pub mod` for those modules
- `crates/core/src/error.rs` — new codes only (`sheet.name`, `sheet.id`, `name.defined`, `table.name`, `undo.empty`, `formula.len`)
- Corpora: `tests/corpus/workbook/sheet_names.tsv`, `tests/corpus/workbook/defined_names.tsv`

## Deviations from the spec or the package (with reasons)

- **Packed occupancy + `Vec<CellSlot>`, not a dense `[CellSlot; 65536]` per block.** A dense array blows the 1M×20 / 64 B/cell budget (~8 GB). Packed slots still match “dense slot array plus occupancy bitmap”.
- **`pixel_to_index` is O(log² n)** (binary search over Fenwick prefixes), not strict O(log n). At 1M rows that is < 400 operations; the bench still scales with log n. `index_to_pixel` is O(log n).
- **Counting allocator is structural `heap_bytes()`, not `#[global_allocator]`.** Workspace `unsafe_code = forbid` cannot wrap `System`. RSS is also recorded from `/proc/self/statm` (4096-byte page assumption).
- **Geometry stores pixels**, not Excel point/character units. Defaults 20 px / 64 px. Conversion is WP-06/UI.
- **`lib.rs` module list is rustfmt-alphabetical.** New mods are inserted in that order rather than appended after `value`, so `cargo fmt --check` is green. WP-01 modules keep their relative order.
- **New `error::codes` constants** (`sheet.name`, …, `formula.len`) extend the module without changing frozen WP-01 signatures. `docs/contracts.md` was not edited.
