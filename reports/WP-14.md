## What was built

Toolkit-free `omacell-ui`: one `UiSession` consumes a `LoadedConfig` snapshot and keymap search roots (never `Paths::from_env`). Package maps are loaded under bounded, root-confined reads; sparse selected-config/user maps overlay the shipped map. Classic/modal dispatch supports normalized chords, counts, multi-key chords, and `<leader>` expansion. The conformance gate rejects duplicate chords, unknown modal tables, unowned commands, and stale deferred entries that have already registered.

WP-14-owned commands (`view.*`, `nav.*`, `sel.*`, `mode.*`, edit/palette/help) register on the bus against the session mutex. External UI state changes only during the live bus pass, while edit commits validate on the scratch workbook and write through the live command context exactly once. Navigation includes actual data edges, connected current regions, sheet selection, viewport-sized pages, modal screen positions, and active-sheet synchronization. Typed schemas are exposed for `view.zoom` and `view.select`; later-WP actions remain in the explicit deferred table instead of registering silent no-ops.

The post-WP-27 audit reconciled that ownership table with the live CLI composition. Fifty ids already registered by WP-13/17/18/23/26 were removed, the UI conformance fixture now composes every bus-owned command family, and a CLI integration test rejects any future entry that is both registered and marked deferred. Eleven genuinely missing frontend integrations remain explicit rather than being mixed with landed commands.

Editing now has Unicode-safe caret/delete operations, point-mode input, localized separator canonicalization, range- and sheet-safe F4 anchoring, formula-bar/in-cell shared state, real commit/undo behavior, and classic/modal commit transitions. Clipboard and session encoders enforce the WP-08/1 MiB bounds. Clipboard TSV/CSV quoting handles tabs, CR/LF, and quotes. Viewport hit testing includes scroll/frozen offsets and hidden geometry. Selection arithmetic is overflow-safe and exposes a toolkit-independent statistics provider. Palette AI/schema-prompt hooks and explicit session model setters make the retained models usable by WP-15/WP-16.

The integration tests also exposed a pre-existing recalc defect: circular/iterative cached-value commits could create an undo unit above the user's edit. Recalc-derived writes are now consistently excluded from undo, with a core regression test.

Key files: `crates/ui/src/*.rs`, `crates/ui/tests/*`, `default/keys/{classic,modal}.toml`.

## Deviations from the spec or the package (with reasons)

- **Command ids cannot contain `_`** (frozen `CommandId`). Appendix A names like fill-down become `edit.filldown`, `nav.pagedown`, `file.saveas`. Documented for keymap authors.
- **`view.freeze` writes `UiSession` only**, not sheet `ViewState`. Persisting freeze into the file is WP-16/save.
- **Contextual deferred ids avoid frozen-schema collisions.** Delete maps to `edit.clearcell`, and the number preset maps to `format.numberstyle`, both owned by WP-17; binding the frozen `cell.clear` / `format.number` schemas without required range arguments would fail at runtime.
- **`?` in the palette** returns a WP-23 hint when no `AiPlanProvider` is supplied; no network.
- **Fill series** detects copy vs linear/date from numeric deltas; full growth/calendar/custom-list semantics and mutation commands are WP-17.
