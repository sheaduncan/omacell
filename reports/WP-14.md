## What was built

Toolkit-free `omacell-ui`: one `UiSession` consumes a `LoadedConfig` snapshot and keymap search roots (never `Paths::from_env`). Keymaps load classic/modal TOML with counts, multi-key chords, and `<leader>` expansion. WP-14-owned commands (`view.*`, `nav.*`, `sel.*`, `mode.*`, edit/palette/help) register on the bus against the session mutex. Later-WP bindings stay in a tested deferred table.

Key files: `crates/ui/src/*.rs`, `crates/ui/tests/*`, `default/keys/{classic,modal}.toml`.

## Deviations from the spec or the package (with reasons)

- **Command ids cannot contain `_`** (frozen `CommandId`). Appendix A names like fill-down become `edit.filldown`, `nav.pagedown`, `file.saveas`. Documented for keymap authors.
- **`view.freeze` writes `UiSession` only**, not sheet `ViewState`. Persisting freeze into the file is WP-16/save.
- **`?` in the palette** returns a WP-23 hint via `AiPlanProvider` absence; no network.
- **Fill series** detects copy vs linear/date from numeric deltas; custom lists are WP-18.
