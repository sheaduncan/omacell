## Deviations from the spec or the package (with reasons)

- **Bootstrap-time CI limitation (resolved).** WP-00 predated the GitHub remote.
  The public remote now has an active `main` ruleset requiring pull requests and
  the strict `check` status; subsequent PRs provide the hosted-CI evidence.
- **No `assert_cmd`.** The version smoke test uses `std::process::Command` and `CARGO_BIN_EXE_omacell` so this package adds zero crates.io dependencies.
- **`crates/ui` is in the workspace.** Spec §11.6 omits it; WP-00 and `AGENTS.md` require it.
- **Plan D3 (egui) vs spec ADR-001 (Qt Quick for the spike).** Both are recorded on ADR-0001 as *proposed*. Not resolved here.
- **Local merge to `main`.** WP-00 says open a PR and do not merge. There is no remote, and the request was to stand up an organized repo, so `wp/00-bootstrap` was merged locally after `just check`. Future packages should still PR.
