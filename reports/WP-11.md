## What was built

A line-oriented UTF-8 `.omc` codec in `crates/io::omc`. Workbooks round-trip through `.xlsx` at L1/L2 (minus L3 binaries listed on `ConversionReport`). Complete changesets serialize as `change` records, including summary counters and exact `CommandCall` JSON for `forward` and `inverse`. CF/DV/print/sparklines travel as opaque `extra` records until WP-18 models them. `aicache` is reserved (skipped). CLI remains WP-13.

Review fixes made the field parser strict and type-aware: syntactically quoted
typed literals stay text, key/value fields are encoded as a whole, unknown
escapes and malformed quoting are rejected, and `open_str` now enforces the
same NUL/size caps as `open_bytes`. The lossless records now include workbook
settings/metadata, complete sheet views/geometry/protection/tab colors, rich
cell text, arrays, threaded comments, hyperlink tooltips, complete table flags
and columns, defined-name comments/sheet-qualified ranges, and all changeset
summary fields. Custom part paths are constrained to `xl/omacell/` and checked
case-insensitively for collisions. The pre-WP-28 integration pass adds
`cse_ref=` on legacy array-formula anchors so fixed CSE ranges survive an OMC
round trip without becoming dynamic spills.

## Deviations from the spec or the package (with reasons)

- **Style records are JSON**, not only the sketch `font=monospace;bold` form. The sketch compact form is still accepted on read. JSON is required for L2-equal styles (theme colours, custom `numFmtId`).
- **CF / validation sketch records** are stored as opaque `extra` payloads, not a typed CF engine (WP-18). The Appendix E `cf` / `validation` lines parse as extras so the sketch file loads.
- **Binary L3** (theme, drawings, VBA, media) is reported dropped, not base64’d (F-9.3).
- **Rich text inside array values or defined-name constants is rejected**, not
  flattened. The frozen `Workbook` API can intern rich text only while setting
  a cell; ordinary rich-text cells and formula caches round-trip exactly.
- **`omacell changeset export --omc`** is WP-13 over `changeset_to_omc`.
