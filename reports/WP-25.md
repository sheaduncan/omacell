## What was built

A chart/sparkline model on `Sheet`, a toolkit-neutral `Scene`, and one layout path consumed by SVG, PNG (`resvg`/`tiny-skia`), and the egui painter. Sampling re-reads workbook ranges after recalc. `chart.fromselection` / `sparkline.set` are registered commands (F11 injects the current selection). Both commands now participate in direct undo/redo and provide trusted inverses for changeset apply/revert.

Modeled charts write and read the appropriate DrawingML structures for every core kind, including scatter X/Y ranges, bubble sizes, combo secondary series, axes, titles, legends, labels, trendlines, colors, and anchors. Exotic chart types become opaque placeholders; their original drawing package remains authoritative. New and imported sparklines share the model, while unchanged raw `x14` fragments remain byte-identical. Changed sparkline state is regenerated from the model instead of being silently discarded by stale worksheet extras.

The review pass also added bounded sampling/raster allocation, strict command enums, chart/sparkline value validation, SVG/XML sanitization, cross-sheet range serialization, and correct GUI font scaling.

## Deviations from the spec or the package (with reasons)

- **`chart.export` lives in the CLI composition root.** The bus crate still does not take an `io` dependency; the public command and `omacell convert ….{svg,png}` now share the same bounded renderer, theme adapter, validation, and atomic writer.
- **Excel-authored exotic charts stay opaque L3 copies.** Their title/source ranges are modeled for a placeholder, while the original drawing remains authoritative. `chart.fromselection` refuses to add a chart to such a sheet because regenerating it would either discard the opaque drawing or silently omit the new chart.
- **Histogram writes as a bar chart of bins**, not `c15:histogramChart`.
- **Sixel/kitty chart bitmaps** are still named by `graphics_protocol`; the TUI shows unicode sparkline glyphs.
- **Chart builder panel is the existing docked panel plus F11**, not a full property inspector; property editing and move/resize remain WP-28 work.
- **`resvg`/`usvg`/`tiny-skia`** are pre-approved. `RUSTSEC-2026-0206` (`rustybuzz` via usvg) is ignored until resvg drops it.
- **`insta` 1** on `omacell-core` for SVG goldens (already used by TUI/CLI).
