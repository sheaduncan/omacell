## What was built

A chart/sparkline model on `Sheet`, a toolkit-neutral `Scene`, and one layout path consumed by SVG, PNG (`resvg`/`tiny-skia`), and the egui painter. Sampling re-reads workbook ranges after recalc. `chart.fromselection` / `sparkline.set` are registered commands (F11 injects the current selection). Modeled charts write DrawingML; sheets without modeled charts keep WP-10 L3 drawing copies. New sparklines write `x14` when extras are empty; corpus `sparkline_xml` extras still win for byte-identical round-trip.

Key files:

- `crates/core/src/chart/{mod,model,sample,scene,svg}.rs`
- `crates/core/tests/chart.rs` + 42 golden SVG snapshots (14 kinds × 3 palettes)
- `crates/io/src/xlsx/drawing.rs`, `crates/io/src/chart_export.rs`, `crates/io/tests/chart_roundtrip.rs`
- `crates/bus/src/chart.rs`
- `crates/gui/src/chart.rs` overlay painter
- TUI unicode sparkline glyphs; CLI `omacell convert book.xlsx out.svg|.png`

## Deviations from the spec or the package (with reasons)

- **`chart.export` remains deferred.** File output is `omacell convert ….{svg,png}` so the bus crate does not take an `io` dependency.
- **Excel-authored exotic charts stay L3 copies** when the sheet has no modeled charts. Our writer regenerates DrawingML only for `Sheet.charts`.
- **Histogram writes as a bar chart of bins**, not `c15:histogramChart`.
- **Sixel/kitty chart bitmaps** are still named by `graphics_protocol`; the TUI shows unicode sparkline glyphs.
- **Chart builder panel is the existing docked panel plus F11**, not a full property inspector (WP-28 polish).
- **`resvg`/`usvg`/`tiny-skia`** are pre-approved. `RUSTSEC-2026-0206` (`rustybuzz` via usvg) is ignored until resvg drops it.
- **`insta` 1** on `omacell-core` for SVG goldens (already used by TUI/CLI).
