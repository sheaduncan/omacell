- Tests first:
  - API tests for every catalogued function
  - `docs/lua-api.md` drift check
  - embedded: `io`/`os`/`require` blocked; infinite loop killed; memory cap; trusted runs, untrusted does not
  - recorder replay equals the recorded model
- Decisions:
  - `mlua` only exposes io/os via an `unsafe` constructor, which this workspace forbids. Both profiles start from `Lua::new()` (safe stdlib). Embedded additionally nils `io`/`os`/`package`/`debug`/`require`/`load*` and applies instruction/memory caps.
  - Untrusted embedded scripts never run (stricter than “sandboxed without trust”); `embedded_scripts=deny` blocks even trusted embedded scripts.
  - `ask` is treated as `deny` in non-interactive CLI (never prompt on open).
  - Trust is CLI-only, not a bus command (models must not alter trust).
  - `init.lua` loads for interactive surfaces and `omacell run` / `script.source`, not every one-shot `query`/`set`.
  - Custom function names must be namespaced (`USER.DOUBLE`).
  - Python bridge is experimental stdio JSON-lines; skipped if `python3` is absent.
- Open questions at planning time:
  1. Whether GUI/TUI should auto-load `init.lua` in this package (yes, via a helper they can call; CLI `run` always can).

## What was built

Sandboxed Lua 5.4 (`mlua`, vendored) with the documented `omacell.*` API, a SHA-256 trust store, a command recorder that emits replayable Lua, and CLI `omacell run` / `omacell trust`.

- `crates/lua` — runtime, catalog, trust, recorder, bus host, `macro.*` / `script.source`
- `crates/core` — `FnRegistry::register_dynamic` so `omacell.fn` participates in recalc
- CLI: `omacell run [--embedded] [--python]`, `omacell trust add|remove|list`
- `docs/lua-api.md` generated from `catalog::API`

Key tests: `crates/lua/tests/{api,sandbox,recorder}.rs`.

## Interfaces exposed (for dependents)

- `Runtime`, `Profile::{User,Embedded}`, `ScriptPolicy`, `allow_embedded`, `BusHost`
- `TrustStore`, `hash_path`, `trust_path`
- `Recorder`, `replay_lua`
- `register_script_commands` (`macro.record` / `macro.stop` / `macro.save` / `script.source`)
- `FnRegistry::{register_dynamic, lookup_dynamic, iter_dynamic}`
- CLI: `omacell run`, `omacell trust`
- Embedded part: `xl/omacell/scripts/main.lua`
- Caps: 1e6 VM instructions, 8 MiB memory (embedded)

`omacell.ai.*` errors with WP-23.

## Deviations from the spec or the package (with reasons)

- User scripts do not get `io`/`os` (workspace `forbid(unsafe_code)` vs mlua's unsafe constructor). Documented in known-differences.
- `ask` ≡ `deny` in the CLI.
- One-shot `query`/`set` do not load `init.lua`.
- Python `--python` is a JSON-lines stdio child, experimental.
