## What was built

Sandboxed Lua 5.4 (`mlua`, vendored) with the documented `omacell.*` API, a SHA-256 exact-byte trust store, a bus-connected command recorder that emits replayable Lua, and CLI `omacell run` / `omacell trust`.

- `crates/lua` — runtime, catalog, trust, recorder, bus host, `macro.*` / `script.source`
- `crates/core` — `FnRegistry::register_dynamic` so `omacell.fn` participates in recalc
- CLI: `omacell run [--embedded] [--python]`, interactive prompts, exact-byte embedded parsing/trust, `omacell trust add|remove|list`
- Python bridge: frozen IPC v1 request/reply envelopes, modes/changesets, 1 MiB frame cap, and child cleanup on protocol failure
- `docs/lua-api.md` generated from `catalog::API`

Review fixes on PR #39 also close the following issues found behind the original green CI:

- Embedded scripts can no longer escape `io`/`os` restrictions through `file.*`, `macro.*`, `script.*`, or `theme.*` bus commands, including indirect `edit.repeat` replay. Coroutine and protected-call instruction-budget bypasses are removed.
- Trust covers the same byte slice used to parse the workbook; the CLI refuses a concurrent on-disk change before saving.
- `omacell.cmd` returns command results, preserves nested JSON arrays, and dispatches resulting bus events to registered Lua hooks. Cell formulas/styles and text/array custom functions are modeled, and worksheet functions cannot re-enter host APIs.
- Macro commands run external effects only after preflight, models cannot invoke macro control or `script.source`, successful committed commands are recorded automatically, capture is bounded, and replay uses the capped Lua parser rather than textual substitution.
- Trust-store hashes are validated, hashing is streaming, the store is bounded, and writes use exclusive mode-0600 temporary files plus rename.

Key tests: `crates/lua/tests/{api,sandbox,recorder}.rs`.

## Deviations from the spec or the package (with reasons)

- User scripts do not get Lua's unsafe `debug` library or native C-module loading; they do get `io`, `os`, `package`, and Lua-module `require`. Documented in known-differences.
- Embedded scripts do not get `coroutine`, `pcall`, or `xpcall`: mlua's hook is thread-local and Lua hook errors are catchable, so retaining those APIs would bypass the hard instruction cap.
- `ask` ≡ `deny` in the CLI.
- One-shot `query`/`set` do not load `init.lua`.
- Python `--python` is an experimental IPC-v1 JSON-lines stdio child.
- Retained GUI/TUI worksheet callbacks preserve closures on normal calculation passes. Calculation that overlaps a running hook uses a self-contained isolated callback VM to avoid a cross-thread Lua deadlock; such callbacks cannot depend on captured locals on that overlapping path.
