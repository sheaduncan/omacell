## What was built

`crates/ai` talks to models through two wire protocols, builds a redactable workbook card, and is the only place workbook content is serialized for a model. Tests never open a socket: `ReplayTransport` matches a canonical JSON POST against `tests/fixtures/ai/*.json`. Production HTTP is `reqwest` + rustls, used only outside CI.

Key files:

- `crates/ai/src/{lib,error,http,provider,openai,anthropic,secrets,policy,redact,card,audit,budget,setup}.rs`
- `crates/conf/src/edit.rs` — sparse `toml_edit` patch for `omacell ai setup`
- `crates/cli/src/ai.rs` — `omacell ai setup|card|log|usage`
- `docs/schemas/card.schema.json` (freezes with this package)
- `default/ai/prompts/card.md`
- Fixtures: `tests/fixtures/ai/{openai,anthropic}_{structured,tools,stream,error,timeout}.json`

Tests:

- `crates/ai/tests/provider.rs` — both protocols: structured output, tools, streaming, errors, timeouts, cancellation
- `crates/ai/tests/privacy.rs` — schema strips values; detectors on the card path; workbook override; loopback `local_full`; accepted `ai.redact` marks; cell-input/image-alt strings
- `crates/ai/tests/card.rs` — insta goldens at every level
- `crates/ai/tests/leak.rs` — secret string absent from config and logs
- `crates/ai/tests/budget.rs` — rate limit and `max_cells_per_recalc`
- `crates/cli/tests/ai.rs` — `omacell ai setup` in temp `$HOME` with loopback listeners; `card`/`log`/`usage --json`

MCP `card` args stay empty (WP-21 freeze). CLI injects a `CardHook` so `omacell mcp` returns a WP-22 summary card; bus tests without a hook still use `stub_card`.

## Deviations from the spec or the package (with reasons)

- **MCP `card` arguments stay empty.** WP-21 froze the catalog. Summary is the MCP payload; `--level` is CLI-only.
- **Detected patterns are redacted on every payload**, and also listed as suggestions until `ai.redact` marks are accepted. Spec A-7.2 says suggestions until accepted; leaking the sample until then would defeat privacy tests.
- **`omacell ai setup` enables AI only when a local server is found.** Presence of the Omarchy default agent does not flip `[ai] enabled` (agent path needs no provider). An empty detection pass does not write `enabled = false`, so a cloud setup is not disabled.
- **`bus` does not depend on `ai`.** The real card is a `CardHook` from the CLI composition root.
- **Diagnostic bundles:** `omacell agent diagnose` runs `redact_json` before write. GUI/TUI diagnose still goes through `core::redact_identity` (identity) so those crates do not take a `reqwest`/`tokio` dependency; WP-23 can share the CLI path.
- **No live recorder binary.** Humans capture exchanges into `tests/fixtures/ai/*.json`. Replay matching is canonical JSON (BTree map order).
- **Token estimate is `ceil(chars/4)`**, no tokenizer crate.
