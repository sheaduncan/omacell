## What was built

Typed and validated Appendix B `Config`, deep-merge layering with provenance and migrations, explicit config-file and workbook-settings adapters, Omarchy `colors.toml` → color roles (Appendix C mapping, mix, light-mode direction, contrast nudge), rendered/user/CLI theme overlays, loadable shell/font tokens, live reload with last-good semantics, and conservative `setup omarchy` filesystem actions. CLI remains WP-13.

The 2026-09-04 hardening follow-up makes color parsing safe for arbitrary
Unicode, contains malformed ambient Omarchy themes with a neutral fallback
while keeping explicit/user themes strict, and leaves a usable last-good store
when watcher creation fails. Paths now honor absolute XDG config/state roots.
Schema migration preserves comments, formatting, symlink intent, and target
permissions. Omarchy setup recognizes JSONC menu commands independent of
spacing or labels, installs a no-instance-safe theme hook, and exposes a
conservative uninstall operation that removes only unchanged owned assets and
exact menu rows. CLI integration tests that replace `HOME` now also isolate XDG
roots so they cannot consult or mutate the developer's real configuration.

The 2026-09-02 environment-filter follow-up derives the configuration
environment allowlist from the complete package-default leaf set before any
untrusted overlay is merged. Recognized `OMACELL_SECTION__KEY` values retain
their original precedence, provenance, and typed validation; unrelated
`OMACELL_*` process controls are ignored. This prevents
`OMACELL_REDUCED_MOTION=1`, which the GUI consumes directly, from becoming an
unknown root config field and aborting GUI or TUI startup.

## Deviations from the spec or the package (with reasons)

- **`[config] live_reload` / `debounce_ms`** are extra keys so the library can watch without a CLI.
- **`ReloadEvent` lives in `conf`**, not frozen `core::Event` (non_exhaustive but G0-frozen). WP-13 can map it.
- **SIGUSR1** is `ConfigStore::reload`; the binary binds the signal (no `unsafe` in this crate).
- **Portal color-scheme** is best-effort zbus; tests inject light/dark via `resolve_roles(..., portal_light)`.
- **Keymaps** contain Appendix A chords. WP-14 completed the shared keymap vocabulary and later integration removed every owned command from the deferred table.
- **`cargo deny` ignores RUSTSEC-2026-0192** (`ttf-parser` unmaintained via `fontdb` 0.23, pre-approved).
- **The no-flicker/no-lost-edit-state portion of the theme reload gate** belongs to the WP-16 renderer. This package records the full configuration/theme re-derivation time and preserves all non-file layers during reload.
