## What was built

- AI card columns carry an internal header-source coordinate until policy
  filtering. Accepted marks now redact inferred header names as well as sample
  and cell values, and the coordinate is stripped before serialization.
- Redaction marks follow row/column and band inserts/deletes, cut moves,
  cross-sheet moves, sorts, and sheet renames. Original coordinates are kept as
  conservative lineage so undo/redo cannot reopen a leak; ambiguous range
  permutations lower workbook privacy to `schema`.
- Structural edits rewrite range- and formula-valued defined names and resize
  or remove tables, including their modeled column records, in the same undo
  transaction.
- Sheet deletion invalidates cell/name/table references permanently, removes
  sheet-owned names and tables, and restores the complete identity graph on
  undo. Sheet rename now rewrites formula-valued names too.
- XLSX worksheet extras are resolved through the original workbook sheet order
  and stable `SheetId`, preserving opaque worksheet fragments across rename,
  reorder, and deletion.
- A central command-bus protection preflight enforces locked cells, permitted
  sheet actions, editable protected ranges, and workbook structure protection.
  Reconfiguration/unprotect requires the current legacy password hash.
- Row and left-to-right sorts apply their permutation to notes, threaded
  comments, and hyperlinks as part of the same undoable edit.
- `omacell-io` now provides a bounded autosave store and per-window coordinator.
  Retained frontends asynchronously write copy-on-write XLSX snapshots to the
  documented state directory, discover source-matching snapshots on launch,
  restore the newest valid candidate while retaining the original save path,
  notify the user, and clear state after save or confirmed discard.
- CSV/TSV and OMC now use the shared lock-aware, backup-rotating, cancellable,
  fsynced atomic writer.
- JSON import/export limits use `json.limit`, and import checks the rectangle
  implied by `rows × union(keys)` before workbook construction.
- The GUI font cache snapshots the families active in egui at the start of a
  frame. A family discovered from workbook content uses the bound monospace
  fallback for that frame and becomes selectable after egui activates its
  definition, preventing workbook-controlled font names from panicking paint.
- The GUI now enables native Vulkan and GLES features explicitly on its direct
  wgpu dependency, so standalone builds no longer rely on test-only feature
  unification to provide a renderer.
- Omarchy hand-offs now spawn with detached standard streams and are reaped on
  a named background thread. Retained frontends and `omacell agent` return as
  soon as the launcher starts instead of waiting for the agent terminal to
  close.
- In the classic GUI, committed toolkit text now starts an empty in-cell edit
  when the grid is selected, preserving the usual overwrite-on-type behavior
  without double-inserting the corresponding key event. A plain cell
  double-click now selects that cell and opens its existing input for editing.
  Identical adjacent plain-text and IME commits are coalesced as one platform
  input pair; repeated pairs remain repeated characters.

## Interfaces exposed (for dependents)

- `omacell_io::autosave::{AutosaveStore, AutosaveSession,
  RecoveryCandidate}` is an internal cross-crate composition API for the two
  retained frontends. It does not alter a frozen wire or workbook contract.
- `omacell_io::error::codes::JSON_LIMIT` (`json.limit`) distinguishes JSON
  resource limits from XLSX container limits.

## Deviations from the spec or the package (with reasons)

- Redaction transforms deliberately retain prior coordinates as fail-closed
  lineage instead of adding a new custom-part undo delta. This can over-redact
  after repeated edits, but avoids changing the frozen public `Delta` contract
  and prevents undo/redo disclosure. Ambiguous intersections force schema-only
  payloads.
- Recovery snapshots contain workbook state but start a fresh undo history
  after a process crash. Autosaving a live session serializes a clone and never
  clears or alters that session's undo history, satisfying the within-session
  durability requirement.
