## What was built

In-app AI features, all mutations through the command bus / changesets. `evaluate()` is non-blocking; `settle()` batches pending AI cells (default 50) and `block_on`s chats. Cache is content-addressed in `xl/omacell/aicache.json` plus `~/.cache/omacell/ai/{hash}.json`, keyed by arguments and invalidated when the prompt-template version or model changes (pinned entries are kept).

## Deviations from the spec or the package (with reasons)

- **200 plan evals are structured JSON, not 200 HTTP recordings.** Exact command match and `to_calls` are the gate; HTTP is covered by in-test `Transport` doubles for cell batches.
- **Lua `omacell.ai.fn` is not an async graph node.** `DynamicFn` has no `async_node`; the function returns `#N/A`. Named tasks are stored; worksheet AI functions are the six builtins.
- **`ai.plan` / `ai.agent.turn` are queries.** They return a validated command list. Apply is `changeset.propose` + user apply (`Origin::PalettePlan` / `InAppAgent` cannot apply themselves).
- **Import assist never writes the live plan.** It returns `{current, proposed, applied: false}`.
- **Panel UI is not in this package** (WP-16/WP-15 follow-up). Palette `?` and `Ctrl+Shift+A` (`ai.plan`) are wired.
- **Excel `COPILOT()` is not mapped to `AI()`** (open-question HUMAN).
- **`omacell-ai` depends on `omacell-io`** for `ImportPlan` (io does not depend on ai).
