## Fix first

These are the confirmed items with the widest user-visible or security impact.
Each was re-verified by the lead reviewer in the source.
1. **Sort, insert/delete cells and overlapping moves corrupt text and formulas in
   any workbook opened from disk.** `Workbook::replace_slot`
   (`crates/core/src/workbook.rs:1172-1191`) releases the old slot's interned
   ids before the undo log takes its own hold, and `StringTable::release`
   (`crates/core/src/intern.rs:198-214`) recycles an id at zero. Cells loaded
   by every reader hold exactly one reference because loading runs with the
   undo log disabled (`crates/io/src/xlsx/read.rs:71,223`). `sort.rs:296-328`
   copies slots and writes them back: A1 <- banana frees `apple`, then A2 <-
   apple points at a dead id and shows `""` (and later an unrelated string
   once the id is reused). `ops.rs:355-431` (`shift_band_rows/cols` clears the
   whole band before re-setting) and `ops.rs:2160-2183` (overlapping
   `move_range_cells`) have the same pattern. Tests pass because
   `Workbook::new()` keeps undo enabled, which adds a second reference.
2. **Dependents stop recalculating after the second edit of a former formula cell.**
   `crates/core/src/graph.rs:240-258` `remove_node` deletes the node together
   with its `cell_dependents` reverse edges, and `notify_edit`
   (`crates/core/src/recalc.rs:517-530`) never rebuilds them. A1 `=1+1`,
   B1 `=A1*2`; type `5` into A1 (B1 becomes 10); type `7` into A1: B1 stays 10.
   Reachable through `cell.set`, which runs with `rebuild: false`.
3. **Renaming a sheet turns every cross-sheet formula into `#REF!`.**
   `Workbook::rename_sheet_inner` (`crates/core/src/workbook.rs:1794-1825`) and
   the bus `sheet.rename` handler never rewrite formula text;
   `RewriteOp::SheetRename` exists but its only caller is a test.
4. **Unary minus binds looser than `^`.** `crates/core/src/formula/parser.rs:840-841`
   sets `BP_UNARY=50 < BP_POW=60`, so `=-2^2` gives -4. Excel gives 4. The
   corpus rows `tests/corpus/eval/operators.tsv:9` and
   `tests/corpus/formulas/valid.tsv:70,760` enshrine the wrong value; the
   spec's own precedence list (`docs/spec/omacell-design-spec.md:185`) says
   unary binds tighter.
5. **COUNTIF/SUMIF/AVERAGEIF family treat blanks as 0, FALSE and "".**
   `crates/fn/src/common.rs:790-822` walks the full rectangle and falls back
   to `coerce::compare_op`, where blank equals 0. `=COUNTIF(A:A,"<5")` with
   one value returns about 1,048,575; `=COUNTIF(A1:A4,"*")` counts numbers,
   booleans and blanks because the wildcard path formats them as text.
6. **ROUND/ROUNDUP/ROUNDDOWN/TRUNC operate on the raw binary product.**
   `crates/fn/src/common.rs:135-166`. `=ROUND(1.005,2)` gives 1 (Excel 1.01),
   `=ROUNDDOWN(0.29,2)` gives 0.28, `=TRUNC(0.57,2)` gives 0.56.
7. **Theme colours are mapped in the wrong order and tint is discarded.**
   `crates/io/src/xlsx/read.rs:922-931` resolves `theme="1"` (Excel "Text 1",
   black) to scheme slot 1, which is `lt1` (white), and `let _ = tint;` drops
   the tint. On save `write.rs:1218` hard-codes the resolved RGB, so a normal
   Excel workbook with a bold black header comes back white-on-white.
8. **Excel future-function prefixes are never handled.** No `_xlfn`, `_xlpm`
   or `_xlws` handling exists in `crates/io` or `crates/core`. Files using
   `XLOOKUP`, `IFS`, `STDEV.S`, `LET`, `SEQUENCE`, `FILTER`, `LAMBDA` open with
   `#NAME?` and are written back so that Excel shows `#NAME?`.
9. **Defined names lose their sheet qualifier.** `read.rs:346-353` keeps only
   `parsed.kind`; `write.rs:746-748` cannot print a sheet; evaluation
   (`crates/core/src/eval/mod.rs:1041`) falls back to the formula's own sheet.
   `Rate = Sheet1!$A$1` used on Sheet2 reads Sheet2!A1 with no warning.
10. **x14 extension fragments are re-emitted outside `<extLst>` without their
   namespace.** `read.rs:969-979` and `write.rs:1486-1526,1668-1677`. Any
   Excel 2010+ file with a data bar, icon set, cross-sheet list validation or
   sparkline triggers Excel's repair prompt after a save. Preserved
   `autoFilter`/`dataValidation` blobs carrying `xr:uid` have the same problem
   because the regenerated root (`write.rs:1334-1336`) does not declare `xr`.
11. **The AI HTTP client honours the system proxy and follows redirects.**
    `crates/ai/src/http.rs:106-109` builds `reqwest::Client` with defaults.
    With `HTTP_PROXY` set, the shipped "local" Ollama provider
    (`default/config.toml:105-108`, `local_full = true`) sends full-level
    cards and `AI()` arguments through the proxy in cleartext while the status
    line says local. Redirects re-POST the body and keep the Anthropic
    `x-api-key` header across hosts (reqwest strips only `Authorization`).
12. **`edit.repeat` lets any IPC client execute changeset-eligible mutations
    live.** It is registered `Mutating`, not eligible
    (`crates/bus/src/edit.rs:998-1008`), so `crates/bus/src/ipc/dispatch.rs:171-183`
    defaults it to execute, and it replays the last eligible command up to
    1000 times with no proposal.
13. **Every changeset-eligible command clones the workbook and diffs all cells.**
    `crates/bus/src/session.rs:655-665` clones before each eligible call and
    `restore.rs:96-208` builds two `BTreeMap`s over every stored cell to
    compute an inverse, twice per direct command (preflight and live), and
    then discards it. Ctrl+B on a 1M×20 workbook allocates gigabytes.
14. **The TUI cannot type a space into a cell.** `crates/tui/src/input.rs:16`
    maps `Char(' ')` to `KeyCode::Space`; the editing branch of
    `crates/ui/src/session.rs:582-585` inserts only `Char(c)`, so the space
    falls through to the keymap (where it is the modal leader).
15. **Any `OMACELL_*` environment variable breaks startup.**
    `crates/conf/src/layer.rs:516-537` injects every `OMACELL_*` variable
    except two into a `deny_unknown_fields` config. `OMACELL_REDUCED_MOTION=1`,
    which the GUI itself reads, makes the GUI and TUI refuse to start.
16. **Crafted legacy `.xls` files abort the process.** `crates/io/src/bridge.rs:125-150`
    validates bounds only after calamine has allocated a dense `rows×cols`
    grid; calamine 0.36 also has an unguarded DIFAT loop and unchecked FAT
    indexing (`cfb.rs:115-118,322-331`). calamine is a runtime dependency
    (`crates/io/Cargo.toml:17`) although AGENTS.md lists it as dev-only, and
    `reports/WP-27.md` neither names nor justifies it.
17. **The Omarchy VM workflow can never pass.** `.github/workflows/omarchy.yml:41-42`
    exports `OMACELL_SOURCE_URL`/`OMACELL_SOURCE_SHA256`, but the recipe reads
    `PKGBUILD_SOURCE_URL`/`PKGBUILD_SOURCE_SHA256` (`packaging/PKGBUILD:32-33`,
    renamed in 8d57aa3). `makepkg` falls back to a v0.0.0 tarball URL that
    does not exist. Gate G7 ("VM job green on three channels") is unsatisfiable.

## Findings by area

### Core: formula parser, references, values

- **[high]** `crates/core/src/formula/lexer.rs:792-828,1037-1044` — structured
  reference escaping uses a wrapping-quote model; Excel escapes `[ ] # ' @`
  with a single leading `'`. `=DeptSalesFYSummary['#OfItems]` (Microsoft's
  documented example) fails to parse; `[O''Brien]` yields the wrong column
  name. `tests/corpus/formulas/valid.tsv:445,744,745` encode the non-Excel
  form `[['#Qty']]`.
- **[medium]** `crates/core/src/formula/rewrite.rs:212-235,272-291` via
  `ast.rs:293-301` — structural rewrites descend into `ExprKind::External`,
  so renaming local `Sheet1` rewrites `=[Book.xlsx]Sheet1!A1`, and row
  inserts shift external references. `rewrite.tsv:134` asserts the wrong
  behaviour.
- **[medium]** `parser.rs:1167-1176` — a sheet qualifier on a non-reference
  body is silently dropped: `=Sheet1!SUM(A1)` becomes `=SUM(A1)`.
- **[medium]** `parser.rs:115-121,499` — nesting limit is 63, not 64, and
  parentheses and operators also consume depth.
- **[medium]** `lexer.rs:347-353` — an unqualified structured reference
  containing `.` (`[@Amt.USD]`) is rejected as an external workbook.
- **[low]** `lexer.rs:430-434` `=1e400` becomes `inf` and prints as `=inf`
  (`#NAME?` on re-parse); `parser.rs:153-161` `(A1:B2) (B2:C3)` is parsed as
  a call, not an intersection; `parser.rs:934-944` `=1.5:2` and `=0:0` are
  accepted; two codes (`formula.length`, `formula.len`) for one condition;
  `addr/a1.rs:250-265` does not quote a sheet named `TRUE`; `=Sheet1!Sheet1!A1`
  is accepted; `rewrite.rs:160-182` cut/paste never `#REF!`s references to
  overwritten destination cells; `intern.rs:160-178,332-341` rich-string and
  array interning are linear scans; `deps.rs:111-114` external refs register
  local precedents.

### Core: evaluation, recalculation, workbook

- **[high]** `crates/core/src/graph.rs:677-682`, `eval/mod.rs:1013-1071,1472-1478`
  — self- or mutually-referential defined names (`Loop = Loop+1`, accepted
  from `.xlsx` and `.omc`) recurse without a visited set: stack overflow in
  `DepGraph::rebuild`.
- **[high]** `recalc.rs:745-759,829-831` — INDIRECT/OFFSET targets are not

  previous pass's value.
- **[high]** `spill.rs:146-154` — `blocks_spill` treats any spill-flagged
  cell as non-blocking regardless of owner, so two dynamic arrays can overlap
  and overwrite each other instead of `#SPILL!`.
- **[medium]** `coerce.rs:80-83` — `""` coerces to 0 in arithmetic
  (`A1 =""`, `B1 =A1+1` gives 1; Excel `#VALUE!`). `coerce.rs:114-119` —
  number-to-text coercion uses the 11-character General (`=1/3&""` gives
  `0.333333333`; Excel 15 digits). `coerce.rs:84-89` text `"TRUE"` coerces
  to 1 (Excel `#VALUE!`), while `"1,000"`, `"5%"`, `"$5"` are rejected.
- **[medium]** `eval/mod.rs:1405-1418` — implicit intersection outside the
  vector falls back to the first cell instead of `#VALUE!`, and 2-D ranges
  never intersect.
- **[medium]** `recalc.rs:1250-1263` — CSE results smaller than the target
  pad with `#N/A` instead of broadcasting a scalar, row or column;
  `crates/core/tests/recalc.rs:264-289` locks the wrong behaviour in.
- **[medium]** `lambda.rs:614-618` — `LET` returns as soon as a binding is an
  error; `=LET(x,1/0,IFERROR(x,5))` gives `#DIV/0!`.
- **[medium]** `workbook.rs:1178-1191` with `undo.rs:1307-1328` — every
  recorded delta takes intern refcounts that evicted or cleared transactions
  never release: unbounded string/array growth over a long session.
- **[medium]** `storage.rs:650-669` — `iter_region` filters the whole sheet's
  cells for every range aggregate; `graph.rs:510-543` `precedents_in` is
  O(N) per call, so full recalc of N range formulas is O(N²). The §12.1
  recalc budgets cannot hold on large models.
- **[low]** `eval/ops.rs:91-102` `0^-1` is `#NUM!` not `#DIV/0!`;
  `eval/mod.rs:1230-1261` `=A1#` on a non-origin returns the value instead
  of `#REF!`; a scalar error plus an array collapses to a scalar;
  `storage.rs:591` iteration is block-major, not row-major as documented;
  `graph.rs:330-339` multi-column whole-column refs create 4096 bucket
  entries each; `eval/mod.rs:1794-1813` the AST cache never evicts.
