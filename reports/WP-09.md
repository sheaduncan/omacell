- Items the package says to "decide and document" and the decision taken:
  - **All zip entries are kept** on `OpcPackage` (modeled *and* unknown). WP-10 regenerates modeled parts and re-emits the rest byte-identical.
  - **CF, data validation, sparklines, drawings, charts, VML, VBA, customXml** that we do not map onto core types stay as preserved parts (still L3-safe). Tables, comments, hyperlinks, freeze, merges, print, names, styles *are* modeled.
  - **Shared formulas** expanded with `formula::copy_delta` from the master cell.
  - **`.xlsx` `f` text** is wrapped with `=` before `parse`; failure → cell text + `xlsx.formula` warning.
  - **Column width** Excel chars → pixels via `DEFAULT_COL_PX / 8.43`. **Row height** points → `pt * 96/72`.
  - **Zip limits:** 16 384 entries; 256 MiB/entry; 512 MiB total uncompressed; ratio 100:1 (entries < 64 bytes compressed skipped); XML depth 64.
  - **Theme colors** resolved from `theme/theme1.xml` `clrScheme` when present; missing theme → indexed/auto fallback.
  - **External links** are not followed (F-9.6 / 12.3); the part is preserved.

  2. Date cells typed `d` vs serial `n` with a date numFmt — load both as numbers; style carries the format.
  3. Phonetic runs (`rPh`) — preserve on the SST part; do not model beyond rich `r` runs.

## What was built

OPC zip reader with path/size/ratio limits, a DTD-free depth-capped XML parser, and an `.xlsx`/`.xlsm` loader that fills `Workbook` at L1 (values, formulas including shared-formula shift, number formats) and modeled L2 (styles, merges, freeze/split, names, hyperlinks, tables, comments/notes, row/col size+hidden, sheet visibility, print extras). Every zip entry is retained on `OpcPackage` for WP-10 L3. VBA is never executed. Unparsable formulas stay as text plus `xlsx.formula` warnings.

Key files:

- `crates/io/src/xlsx/{mod,opc,xml,warnings,read}.rs`
- `crates/core/src/workbook.rs` — `pub sheet_mut`, `intern_rich_text`

- Tests: `crates/io/tests/{xlsx_corpus,xlsx_limits,xlsx_warnings}.rs`
- Bench: `crates/io/benches/xlsx_open.rs`

## Deviations from the spec or the package (with reasons)

- **CF, data validation, sparklines, drawings, charts, VML, threaded comments, persons** are not fully modeled in core (WP-18/WP-25). They remain as original zip parts (`OpcPackage`) plus lightweight `WorksheetExtras` tags so WP-10 can re-emit L3 bytes.
- **Phonetic runs (`rPh`)** are not modeled; the SST part is preserved.
- **Theme tints** are stored as `Color::Theme` when the scheme slot is missing; srgb scheme colors are resolved when present.
- **Column width** uses `chars * DEFAULT_COL_PX / 8.43`; **row height** `pt * 96/72`.
- **Corpus generator** uses stdlib `zipfile` so it runs without openpyxl. openpyxl remains the WP-named tool for later richer files.
- **`cargo deny` ignores RUSTSEC-2026-0194/0195** on calamine’s transitive `quick-xml 0.39` (dev-only). Runtime `omacell-io` uses `quick-xml 0.41`. Remove the ignore when calamine ≥ 0.36 fits the MSRV.
