## What was built

OPC zip reader with path/size/ratio limits enforced against actual decompressed bytes, a DTD-free depth-capped XML parser, and an `.xlsx`/`.xlsm` loader that fills `Workbook` at L1 (typed values and formula caches, formulas including shared-formula shift, custom number formats) and modeled L2 (styles, merges, freeze/split, names, hyperlinks, tables, comments/notes, row/col size+hidden, sheet visibility, workbook active view, byte-exact inline worksheet extras). Duplicate and absolute part names are rejected. Every OPC part is retained on `OpcPackage` for WP-10 L3. VBA is never executed. Unparsable formulas stay as text plus `xlsx.formula` warnings.

Key files:

- `crates/io/src/xlsx/{mod,opc,xml,warnings,read}.rs`
- `crates/core/src/workbook.rs` — narrow rich-text, geometry, view, protection, and merge setters; no public raw mutable-sheet access
- `scripts/corpus-gen/xlsx/gen.py` and `tests/corpus/xlsx/*.xlsx` + JSON sidecars
- Tests: `crates/io/tests/{xlsx_corpus,xlsx_limits,xlsx_warnings}.rs`
- Bench: `crates/io/benches/xlsx_open.rs`
- Fuzz: `xlsx_zip`, `xlsx_sheet_xml`

Key tests: `every_corpus_xlsx_opens`, `l1_matches_calamine_for_all_corpus_cells`, sidecar L2 tests, zip-bomb / DTD / depth / `..` path tests, unparsable-formula warning.

## Deviations from the spec or the package (with reasons)

- **At WP-09 time**, CF, validation, sparklines, charts, threaded comments, and
  persons were opaque handoffs. WP-17/18/25 now model the required L2 surfaces;
  unsupported drawing/VML content remains byte-preserved L3 data by design.
- **Phonetic runs (`rPh`)** are not modeled; the SST part is preserved.
- **Theme tints** are stored as `Color::Theme` when the scheme slot is missing; srgb scheme colors are resolved when present.
- **Column width** uses `chars * DEFAULT_COL_PX / 8.43`; **row height** `pt * 96/72`.
- **Corpus generator** uses stdlib `zipfile` so it runs without openpyxl. openpyxl remains the WP-named tool for later richer files.
- **`cargo deny` ignores RUSTSEC-2026-0194/0195** on calamine’s transitive `quick-xml 0.39` (dev-only). Runtime `omacell-io` uses `quick-xml 0.41`. Remove the ignore when calamine ≥ 0.36 fits the MSRV.

## RFC (only if a frozen contract changed)

WP-01 public types remain unchanged, but this package requires additive `Workbook` methods because `omacell-io` is a separate crate. The initial implementation exposed `Workbook::sheet_mut`, which also exposed `Sheet::store` and could bypass interner refcounts and undo invariants. Review remediation removes that method from the public surface and adds only bounded operations: `set_rich_text`, `set_row_height`, `set_col_hidden`, `set_col_width`, `set_sheet_view`, `set_sheet_protection`, and `set_sheet_merges`.

These are source- and wire-compatible additions; command schemas and IPC are unchanged. They preserve core ownership of the cell store and are used while undo is disabled during construction of a not-yet-published workbook. Merge constituted human approval of this additive frozen-contract change.
