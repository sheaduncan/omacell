## What was built

WP-18 lands the data-tools II surface: sort, AutoFilter, tables, data validation, conditional formatting, and Flash Fill, with file-faithful `.xlsx` extras-win storage.

- **Sort** (`crates/core/src/sort.rs`): multi-key values / fill colour / font colour; custom lists; header; left-to-right; Excel type order (number, text, logical, error, blank last); hidden rows/cols stay put; stable on ties. Cells move as units (value, formula, style). Relative refs are rewritten with `RewriteOp::Copy { drow, dcol }`. Notes/comments do not follow.
- **AutoFilter** (`filter.rs`): value lists, text/number operators, top-N, above/below average, colour, date year/month. Apply hides data rows; header stays visible. `Ctrl+Shift+L` toggles.
- **Tables**: `create_table` / `resize_table` / `convert_table`, `style_name` (default `TableStyleMedium2`), `totals_fn` on columns, auto-expand on adjacent entry, calculated-column formula fill on row expand.
- **Data validation**: whole/decimal/list (inline or A1 range)/date/time/text-length/custom; `validate_cell` and `invalid_cells` (circle-invalid).
- **Conditional formatting**: cell-is, formula, text, blanks/errors, duplicate/unique, top-N, average, color scale, data bar, icon set; priority and stop-if-true. `overlay_at` / `overlay_range` return `CfOverlay { fill, font, source: File | Rule { priority, stop } }` so WP-28 does not eval rules on the UI thread. Color scales use min/mid/max linear interpolation.
- **Flash Fill** (`flashfill.rs`): first/last word, prefix/suffix, surround, constant (2+ identical examples).
- **Bus** (`crates/bus/src/data.rs`): `register_data_commands` wired in CLI and GUI/TUI test composition roots. `DEFERRED_COMMANDS` still names `table.create` / `filter.toggle` / `edit.flashfill` until WP-28.
- **`.xlsx`**: extras-win for corpus CF/DV/autofilter blobs; modeled XML + `dxfs` when extras are empty. Table style name and totals functions round-trip.

Evidence: `crates/core/tests/data_tools.rs`, `crates/bus/tests/data.rs`, `crates/io/tests/xlsx_roundtrip.rs::wp18_modeled_filter_dv_cf_roundtrip`.

## Deviations from the spec or the package (with reasons)

- Slicers remain Tier 1, as the package says.
- `name.manager` / `name.paste` / `name.createfrom` stay in `DEFERRED_COMMANDS` (keymap ids); they are name-manager UI, not F-6.1–F-6.5.
- Color-scale interpolation is min/mid/max linear RGB, not Excel's exact percentile algorithm (planning decision).
- Icon-set overlay does not emit icons (GUI); numeric membership uses 3-icon 33/67 percentile defaults when writing modeled XML.
- AutoFilter extras-win still stores only the `ref` string (WP-09/WP-10). Filter *criteria* round-trip on the modeled path (`save_workbook_bytes`); corpus files with a ref-only extra keep the extra.
- Notes/comments do not follow a sort (documented in `docs/compat/known-differences.md`).
- Flash Fill learns first/last word, prefix/suffix, and surround from examples; it is not Excel's full Flash Fill FSM.
